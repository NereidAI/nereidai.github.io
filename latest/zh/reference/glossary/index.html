    术语表¶

    本套件与本站使用的术语。产品的短词与缩写（NS、NF、NFL……）见 命名与简写。

    套件与产品¶

    术语 含义
    NereidAI 平台 / 套件与 GitHub 组织的名称，永不缩写。
    套件（Suite） 八个产品组合使用的形态；每个产品仍可独立运行。
    产品套件 两个轻量套件服务（Sphere、Identity）加六个领域产品。
    轻量层（Thin layer） 只做联邦的组件——门户 / SSO / 网关 / 事件粘合——不含领域逻辑。指 Sphere 与 Mobile。
    独立部署（Standalone） 不使用套件层、单独运行某个产品。它有自己的登录与数据，不依赖其他产品。
    领域产品 端到端拥有完整领域的产品：Link、Forge、Horizon、Edge、Fleet、Mobile。
    商业解决方案 建立在开放平台之上、单独授权的行业方案（NereidFactory、NereidSentinel、NereidMedical）。

    身份与访问¶

    术语 含义
    SSO 单点登录：登录一次即可访问所有被集成的产品。
    Identity（NI） 身份平面，用户的唯一事实来源；当前是可替换 OIDC 引擎背后的 Keycloak realm（nereidai）。
    OIDC OpenID Connect；Sphere 与 Identity 之间使用的身份协议。
    PKCE Proof Key for Code Exchange；用于 OAuth/OIDC 授权码流程。
    票据（密封票据，Ticket） 默认 ns SSO 模式下，Sphere 签发的短时、单次、带受众约束的令牌，由产品服务端到服务端换取已验证身份。
    ns / oidc 模式 两种产品 SSO 集成模式：票据移交（默认）或产品作为自己的直接 OIDC 客户端。Sphere 与产品必须就模式达成一致。
    应急（本地）账号 Sphere 中的本地 bcrypt 账号，仅在身份平面不可达时应急使用，绝不是生产默认。
    RBAC 基于角色的访问控制。权限决定“能做什么”，数据范围（租户 / 客户 / 分组）决定“能触达哪些数据”。RBAC 留在各产品内部。
    租户（Tenant） 多租户产品内的一个隔离客户 / 分区。
    IdP 身份提供方（客户目录）。外部 OIDC / LDAP / SAML IdP 始终经 Identity 背后的代理（brokering）接入。
    身份联邦（Identity brokering） 把外部 IdP 联邦到 Identity 背后，使 Sphere 与产品始终看到相同的签发方与声明。
    服务账号 OAuth2 客户端凭证模式的机器身份，与人类用户分开。
    mTLS 双向 TLS，双方都出示证书。用于服务间与设备到平台的链路。

    安全姿态与交付¶

    术语 含义
    气隙（Air-gapped） 在无互联网访问的环境安装运行；所有镜像与依赖来自离线包 / 内部镜像源。
    回连（Call-home） 强制向厂商发起的出站连接。NereidAI 运行期没有任何回连。
    SBOM 软件物料清单；每次发布的组件清单。
    CVE 公开披露的安全漏洞；企业合同附加响应 SLA 与回填修复。
    LTS 长期支持，带回填修复，按商业条款提供。
    私有镜像仓库 用于替代公共仓库的内部容器镜像仓库（如 Harbor）。
    Helm / chart 部署各产品所用的 Kubernetes 打包方式。
    断点续传（Store-and-forward） 边缘缓冲：广域网中断时把遥测存在本地，链路恢复后重放，不丢数据。
    OTA 空中下载：把 Edge 本身、应用、模型或固件交付到远程节点。
    Rollout（灰度发布） 按策略（分批、百分比、金丝雀）把产物分发到一组节点。
    带宽感知投递 适配受限 / 间歇链路的投递（可续传、分块）。
    协议 / agbot Open Horizon 概念：协议（agreement） 是节点运行某服务的承诺；agbot 负责协商并维护协议。

    Link（IoT）领域¶

    术语 含义
    遥测（Telemetry） 设备上报的时序数据——传感器读数及其他数值或离散采样。
    点位（Measurement point） 一个具名信号（key）；其含义、单位与变换来自所绑定的设备 profile。平台从不臆造单位。
    设备 Profile 可复用模板，描述一类设备如何把原始值映射为工程值。
    描述符（Descriptor） 一个点位定义，含单位、精度与值变换（恒等、线性、查表、表达式、枚举）。
    设备（Device） 已注册、带凭据、可连接的实体；平台从不物理删除设备。
    网关（Gateway） 在平台与无法直连的设备之间中转的设备；一条北向链路、多条南向设备。
    子设备（Sub-device） 经网关接入并归网关所有的设备。
    独立设备 直接接入平台的设备（MQTT / HTTP / CoAP）。
    连接器（Connector） 运行在网关上、由平台管理的协议连接器实例；网关级或绑定到单个子设备。
    边缘密钥（Edge secret） 平台下发给网关存储使用的第三方凭据，区别于网关自身接入平台的凭据。
    凭据（Credential） 设备认证方式：TOKEN、PASSWORD、JWT 或 X.509。
    在线状态（Presence） 对设备当前是否连接的实时视图：在线、离线或未知。
    生命周期状态 设备的运行状态（如在用、隔离、报废），区别于实时连接状态。
    隔离（Quarantine） 可逆的应急锁定：断开设备并拒绝认证，同时保留其身份与历史。
    设备影子（Device shadow） 每设备两份独立文档：desired（目标状态）与 reported（设备最近上报状态）。
    属性（Attribute） 相对静态的元数据，分三个作用域：客户端、服务端、共享。
    规则链（Rule chain） 由规则节点组成的版本化图，路由消息并执行租户定义的逻辑；平台自身不含业务逻辑。
    命令（Command） 发往设备 / 网关的远程操作；单向或请求-响应，读或写，受命令目录约束。
    探测（Probe） 经网关对子设备的按需一次性可达性检查；返回是否应答与时延，不作为遥测存储。
    健康检查（Health check） 连接器周期性读取并丢弃结果；网关据此标记子设备可达 / 不可达。
    告警（Alarm） 带生命周期（触发 → 确认 → 清除）与可选升级的条件。
    升级链（Escalation chain） 针对未处理告警的有序、延迟通知步骤与目标角色。
    转发器（Forwarder） 异步旁路输出，经可插拔通道把数据推到外部系统。
    DLQ 死信队列，处理失败的消息可在此检视。
    固件（Firmware） 经 OTA 交付的设备软件包，带阶段化状态与结构化结果码。
    WebSocket 推送 所有实时更新经此单连接由服务端推送；不使用轮询。
    NATS 消息骨干（Core / JetStream / KV）；Link 内部服务间通信的唯一通道。
    TimescaleDB PostgreSQL 上的时序扩展，用于遥测。

    Forge（模型工厂）领域¶

    术语 含义
    数据集（Dataset） 按标注格式（如 COCO / YOLO）组织的、带版本的图像 / 数据集合。
    标注（Annotation） 对数据做标记（边界框、掩码……），可选 VLM 辅助预标注。
    训练 / 微调 经 Kubeflow 流水线在数据集上产出或适配模型。
    优化 / 量化 在不从零重训的前提下缩小模型体积 / 降低时延（如 NNCF、OpenVINO、TensorRT）。
    导出（Export） 面向目标硬件 / 运行时产出产物。
    多芯片 / NPU 支持的 GPU/NPU 厂商范围；厂商工具链隔离在 Forge 流水线镜像内。
    评估（Evaluation） 评估模型质量 / 跑基准，产出看板指标。
    模型仓库（Model registry） 已产出模型与元数据的版本化存储。
    产物（Artifact） 生产出的、带版本的包（模型或应用），交给 Horizon 做 rollout。
    Kubeflow Pipelines 运行 Forge 训练 / 优化 / 评估流水线的工作流引擎。

    边缘与集群¶

    术语 含义
    EdgeX Foundry Edge 所基于的开放边缘框架（一个 EdgeX 应用服务），跟进上游而非 fork。
    零触碰上线 现场网关启动后安全地自动注册，无需逐设备人工配置。
    本地自治 平台链路中断时，边缘继续运行并执行本地逻辑。
    现场网关 运行 Edge 与现场设备连接器的现场硬件。
    AMR 自主移动机器人；Fleet 调度的一类机器人。
    远程操作（Teleoperation） 人工远程驾驶机器人；走低延迟局域网路径。
    微信小程序 Mobile 的两个目标之一，另一个是移动 App。

    发布与开源¶

    术语 含义
    GA 正式可用；生产就绪门槛（API 冻结、文档完整、签名镜像 + SBOM）。
    Preview 可试用但不稳定；核心流程可跑，契约可能变化。
    Tech Preview 最小可演示切片；无稳定性或升级承诺。
    VERSION 每个仓库的版本文件，是发布与镜像标签的唯一来源。
    Conventional Commits 提交信息约定（feat:、fix:、docs:……）。
    DCO Developer Certificate of Origin；提交用 git commit -s 签名。
