# NereidMedical

**Empower Healing with Intelligent Insights.**

NereidMedical is a **commercial industry solution** for **medical insights**, built
on top of the open NereidAI platform.

!!! note "Commercial solution"
    NereidMedical is licensed, delivered, and supported under a **separate
    commercial agreement**. It is not part of the Apache-2.0 community edition. See
    [Community vs Enterprise](../community/community-vs-enterprise.md).

!!! warning "Not a clinical or regulatory claim"
    This page is a high-level commercial overview. It is not medical advice and
    makes **no regulatory, certification, or clinical-performance claim**.
    Applicable requirements and scope are agreed per engagement.

## The idea

Healthcare and life-science environments concentrate the same pressures that shape
the rest of the platform: highly sensitive data, a strong expectation that it stays
inside the organization, and a need for insight that is timely rather than batched
in the cloud. NereidMedical frames this as a platform problem — ingest data at the
edge, build and optimize models in a private model factory, distribute them offline,
and run inference close to where the data is produced, with no mandatory cloud
dependency.

## What it builds on

A medical-insights solution reuses the same platform building blocks as the rest of
the suite:

| Platform building block | Role for a medical-insights solution |
|---|---|
| [Edge](../products/nereidedge.md) | On-premises data collection with zero-touch onboarding and mTLS. |
| [Forge](../products/nereidforge.md) | Model factory — datasets, training, optimization, and hardware-targeted export. |
| [Horizon](../products/nereidhorizon.md) | Offline distribution of models and apps to remote nodes. |
| [Link](../products/nereidlink.md) | Device access, unified messaging, rule engine, alerting, and dashboards. |
| [Sphere](../products/nereidsphere.md) / [Identity](../products/nereididentity.md) | Portal, API gateway, and unified SSO / RBAC across the suite. |
