# Naming & Abbreviations

Curious where the name comes from and what we are building toward? See
[About NereidAI](../about/index.md).

NereidAI is a suite of eight products. To keep pages and diagrams readable, this
site refers to each product three ways:

| Full name (titles) | Short name (prose) | Abbreviation (diagrams / tables) |
|---|---|---|
| **NereidSphere** | Sphere | NS |
| **NereidIdentity** | Identity | NI |
| **NereidLink** | Link | NL |
| **NereidForge** | Forge | NF |
| **NereidHorizon** | Horizon | NH |
| **NereidEdge** | Edge | NE |
| **NereidFleet** | Fleet | NFL |
| **NereidMobile** | Mobile | NM |

## How they are used

- **Page titles and navigation always use the full name** — for example
  *NereidForge*.
- **Body text uses the short name** after the first mention: *NereidForge
  (Forge)* on first use, then simply *Forge*.
- **Diagrams and dense tables may use the abbreviation** — for example the node
  `NF` in an architecture mermaid diagram means NereidForge.
- **NereidAI** is the name of the platform / suite and the GitHub organization;
  it is never abbreviated.

## Not part of this scheme

- The commercial industry solutions — **NereidFactory**, **NereidSentinel**,
  **NereidMedical** — are separate commercial offerings, not members of the
  eight-product open-source suite, and have no short forms.
- `Edge` (the product NereidEdge) is distinct from the generic word "edge"; in
  prose the short name is capitalized as a product name.

!!! tip "Standalone by default"
    None of these short names imply a runtime dependency. Every product can be
    deployed and used on its own; the short names are only a writing convention.
    See [Standalone by default](../products/index.md#standalone-by-default).
