# User Guides

Step-by-step operator guides for every product. Each guide starts with a
**getting-started** path, followed by page-by-page instructions that mirror the
product's own in-app help center — so what you read here matches what you see on
screen.

Every product works **standalone**; the SSO and portal-jump steps only apply when
Sphere is used as the suite entry point.
