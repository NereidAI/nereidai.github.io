# Catalog

The Catalog in NereidHorizon is a read-only browser for public services and patterns. It shows content published by the Hub and by remote organizations, so you can reference and reuse definitions across organization boundaries without leaving the console.

## What you can do

- Browse the public **services** and **patterns** offered by the Hub and other organizations.
- Click any item to open its details, which are shown as JSON.

The Catalog is a read-only view: it exists for discovery and reference. To create or change a service or pattern, use the [Services](services.md) and [Patterns](patterns.md) modules, or import a definition there after reviewing it in the Catalog.

## Browse the catalog

1. Open the Catalog page.
2. Locate the public service or pattern you want to inspect.
3. Click the item to view its full JSON definition.

## Access errors

| Code | Meaning and action |
|---|---|
| 402 / 401 | You do not have permission to access that organization's catalog; the required authorization must be granted first. |

For cross-organization work that requires elevated credentials, use the **Authorize** action as described on the [Agbots](agbots.md) page.
