# 命名与简写

想了解 Nereid 名字的由来与项目使命，见 [关于 NereidAI](../about/index.md)。

NereidAI 是由八个产品组成的套件。为让页面与图表更易读，本站对每个产品使用三种
称谓：

| 全名（标题） | 短词（正文） | 缩写（图表 / 表格） |
|---|---|---|
| **NereidSphere** | Sphere | NS |
| **NereidIdentity** | Identity | NI |
| **NereidLink** | Link | NL |
| **NereidForge** | Forge | NF |
| **NereidHorizon** | Horizon | NH |
| **NereidEdge** | Edge | NE |
| **NereidFleet** | Fleet | NFL |
| **NereidMobile** | Mobile | NM |

## 使用规则

- **页面标题与导航始终使用全名**——例如 *NereidForge*。
- **正文在首次出现后使用短词**：首次写作 *NereidForge（Forge）*，之后直接用
  *Forge*。
- **图表与密集表格可使用缩写**——例如架构 mermaid 图中的节点 `NF` 即指
  NereidForge。
- **NereidAI** 是平台 / 套件与 GitHub 组织的名称，永不缩写。

## 不在此列

- 商业行业解决方案——**NereidFactory**、**NereidSentinel**、**NereidMedical**——
  是独立的商业方案，不属于这八个开源产品，也没有短词。
- `Edge`（产品 NereidEdge）与泛指的“边缘（edge）”不同；正文中短词作为产品名
  首字母大写。

!!! tip "默认可独立"
    这些短词不代表任何运行时依赖。每个产品都可独立部署、独立使用；短词只是书写
    约定。见 [默认可独立](../products/index.md)。
