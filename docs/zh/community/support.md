# 支持

以下所有途径都通过开放项目或商业协议进行。本站不公布支持邮箱，也没有工单系统——
[NereidAI 的 GitHub 组织](https://github.com/NereidAI) 是唯一的入口。

## 从社区获得帮助

社区支持通过 GitHub 进行。这里**不提供免费技术支援**，也**没有 SLA**——但社区与
维护者都在开放环境中积极活跃。

| 你的需求 | 去处 |
|---|---|
| 报告缺陷或可复现的问题 | 相应仓库的 GitHub **issues** |
| 提问、分享想法、展示你的成果 | GitHub **Discussions** |

!!! tip "发帖之前"
    请先搜索已有的 issues 与 Discussions。开新帖时，请附上版本（`v0.0.1`）、你的
    环境，以及清晰的复现步骤。

## 商业支持多了什么

| | 社区版 | 商业版 |
|---|---|---|
| 渠道 | GitHub issues / Discussions | 专属工程师 |
| 响应 | 尽力而为，无 SLA | 契约化响应承诺 |
| 修复 | 最新版本 | 回补至 LTS 版本 |
| 部署 | 自助 | 交钥匙气隙交付与本地私有 POC |
| 知识转移 | 文档与社区 | 私有化培训 |

商业支持按**独立的商业协议**定义与交付。请见[开源许可与支持](license.md) 与
[社区版与企业版](community-vs-enterprise.md)。

## 联系方式

企业相关咨询——商业支持、部署、定制、NDA 参考，或合作——请通过
**[NereidAI 的 GitHub 组织](https://github.com/NereidAI)**（组织所有者 / Discussions）
联系我们。

本站不公布其他联系渠道。

??? note "社区支持不包含什么"
    社区支持不包含契约化响应时间、专属工程时间、到客户现场的部署，或对旧版本的
    回补修复。这些属于商业能力——请见[社区版与企业版](community-vs-enterprise.md)。
