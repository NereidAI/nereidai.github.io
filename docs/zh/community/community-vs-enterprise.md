# 社区版与企业版

社区版覆盖完整的边缘到云端闭环，可独立用于生产。企业版能力覆盖大型组织在采购、
运营与合规方面的需求。

下表复现了 NereidAI 项目总览中的能力对比。

| 能力 | 社区版 | 企业版价值 |
|---|---|---|
| Edge 连接器与 NPU 适配插件 | ✓ | 同等能力，附带厂商背书的一体化支持 |
| Link / Forge / Horizon，单站点 | ✓ | 多站点规模化——跨多个站点联邦运行、经认证的硬件/加速器组合，以及随 LTS 提供的厂商支持式 rollout |
| Sphere + Identity 多租户控制面 | — | 统一身份与跨产品治理——一次登录、一个门户，整套件内租户与策略一致 |
| Identity 外部 IdP 联邦（OIDC / LDAP / SAML）与 SCIM 供应 | — | 企业 IAM 集成——对接既有目录，自动化用户生命周期管理 |
| 高可用、灾难恢复、大规模 rollout 策略 | — | 规模与韧性——面向不可容忍停机站点的全网 rollout 与 HA/DR |
| 审计、加固、合规基线（等保等） | — | 面向受监管行业与国企 / 跨国采购的合规与审计就绪 |
| 签名发布产物与每版本 SBOM | ✓ | 外加签名离线包与企业供应链流程 |
| CVE 响应 SLA 与回补修复 | — | 契约化的响应承诺，并将修复回补至 LTS 版本 |
| 气隙交付、私有 POC、培训 | 自助 | 交钥匙交付与客户现场的知识转移 |
| 支持 | GitHub issues / Discussions（仅社区，无 SLA） | 7×24 LTS，配备专属工程师 |

## 如何理解这张表

- 社区版一列的 **✓** 表示该能力在 Apache-2.0 社区版中可用；**—** 表示它是商业能力。
- 「社区版」不是残缺版本。社区版是一套完整、可用于生产的边缘到云端闭环。企业版价值
  在于**规模、治理与保障**——运行多站点、满足采购与审计要求，并获得契约化承诺。
- 气隙交付一栏的**自助**表示社区版支持该能力，而商业条款额外提供交钥匙交付与知识转移。

## 安全与交付基线

支撑社区版的同一套基线工作，也决定了哪些是规划中、哪些是商业能力。摘自项目总览：

| 能力 | 状态 |
|---|---|
| 气隙 / 离线安装（完整镜像包，无需互联网） | 可用 |
| 无强制回连；数据保留在客户边界内 | 可用 |
| 服务间与设备到平台的 mTLS 链路 | 可用 |
| 全套件产品统一 SSO 与集中式 RBAC（Identity） | 可用 |
| 签名发布产物与每版本 SBOM | 规划中 |
| CVE 响应与回补修复的企业 SLA | 商业合同 |
| 合规基线（如 等保 2.0）与本地 OS / 加速器认证 | 按需评估的路线图 |
