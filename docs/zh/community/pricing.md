# 价格与购买

NereidAI 采用 open-core 模式，**一套代码、没有隐藏功能**。七个产品全部以 Apache-2.0
开源，可免费用于生产环境，包括商业用途。你可以付费购买的，是围绕同一套软件的保障、
规模治理与交付服务，以及构建在平台之上的行业解决方案。

本页说明：什么免费、什么收费、如何打包、如何购买。本站不公开价目表——每一笔商业
合作都按范围单独报价。任何咨询请发邮件至
[jiekechoo@gmail.com](mailto:jiekechoo@gmail.com)。

## 三种合作方式

| 层级 | 是什么 | 如何付费 |
|---|---|---|
| **社区版** | 七个 Apache-2.0 仓库：完整的边缘到云端闭环，自行部署，社区支持无 SLA | 永久免费 |
| **企业订阅** | 同一套软件，外加 LTS 版本、契约化 CVE 响应、多站点治理、HA/DR 指导、合规支持、交钥匙交付与专属工程师 | 年度订阅，或永久授权加年度维保 |
| **行业解决方案** | NereidFactory、NereidSentinel、NereidMedical：在开放平台之上组合而成的领域产品 | 按项目签约，通常含首年订阅 |

既然代码完全相同，区别就**不是功能有无**，而是谁来运营、附带什么保障。

| 能力 | 社区版 | 企业订阅 |
|---|---|---|
| 七个产品、完整边缘到云端闭环 | 自助使用，免费 | 同一套软件，厂商保障 |
| 边缘连接器与 NPU 适配器插件 | 包含 | 相同能力，加厂商背书的集成支持 |
| 单站点 Link / Forge / Horizon | 包含 | 多站点联邦运营、认证硬件/加速器组合、带 LTS 的受保障发布 |
| Sphere + Identity 多租户管控面 | 包含，自行配置 | 厂商参与设计与支持的统一身份和跨产品治理 |
| 外部 IdP 联邦（OIDC / LDAP / SAML）与 SCIM | 包含，自行配置 | 企业 IAM 集成与自动化用户生命周期交付 |
| 高可用与灾备 | 自行建设与运营 | 参考架构、HA/DR 指导与受保障的大规模发布策略 |
| 审计、加固、合规基线（等保 / MLPS 等） | 工具齐备，合规项目自办 | 面向受监管行业与国企/跨国采购的合规与审计就绪支持 |

| 气隙交付、私有 POC、培训 | 自助 | 交钥匙现场交付、按范围界定的私有 POC 与知识转移 |
| 支持渠道 | GitHub issues / Discussions，无 SLA | 7×24 LTS 支持，配专属工程师 |

## 商业产品如何打包

### 订阅分层

企业订阅提供两个打包层级，具体权益按合作逐案确认：

- **Standard（标准版）**——单站点生产、LTS 更新、工作时间支持、交钥匙气隙交付与
  按范围界定的私有 POC（厂商执行的 POC 属于商业合作，是否收费视范围而定）。
- **Enterprise（企业版）**——多站点联邦运营、HA/DR 与合规支持、7×24 响应加专属
  工程师，以及签名离线包等供应链工作流。

### 订阅如何计量

- **按站点、按年**——主计量单位是客户现场（工厂、园区或数据中心），站点内再按
  节点数分档，小规模部署可以从更低门槛起步。
- **永久授权备选**——走资本开支预算的组织可购买永久授权，另付年度维保费覆盖升级
  与 SLA。
- **行业解决方案**——按工作说明书（SOW）逐项目确定范围，通常打包首年平台订阅。

### 我们刻意不收费的部分

**没有按用量计费**：不按 API 调用次数、推理次数、训练任务数或数据 GB 数收费。平台
为气隙环境而生、无强制回连通道，我们既不能、也不想计量你的业务数据。业务量增长不会
悄悄推高你的账单。

## 如何购买

1. **发邮件**至 [jiekechoo@gmail.com](mailto:jiekechoo@gmail.com)，说明场景——
   站点数、大致设备或网关规模、期望达成的效果。
2. **需求研讨**——范围、部署拓扑、合规与采购约束。
3. **私有 POC 方案**——必要时在客户现场做概念验证，约定成功标准。POC 按合作
   逐案界定，视投入与环境情况可能收费；收费方式会在开工前的方案中写明。
4. **报价与签约**——确定层级、计量单位（订阅或永久授权）、交付与支持条款。
5. **交付与赋能**——交钥匙气隙安装、集成与私有培训。
6. **续费**——年度订阅或维保费持续提供 LTS 更新与 SLA。

## 常见问题

**社区版可以用于营利性的商业部署吗？**
可以。Apache-2.0 允许商业使用、修改与再分发。社区版是完整、可上生产的平台，不是
功能残缺的试用版。

**代码全部开源，我付费买到的是什么？**
运营保障与责任归属：契约化响应时间、回填到长期支持版本的修复、受保障的多站点与
HA/DR 发布、合规项目、交钥匙离线交付、培训与专属工程师。你买的是"有人负责"的
承诺，而不是隐藏功能的钥匙。

**按 API 调用量、数据量或推理次数收费吗？**
不。平台私有化运行、无强制回连，不计量使用情况。收费基于站点、服务层级与项目范围。

**有公开价目表吗？**
没有。气隙企业部署的需求、站点数量、硬件组合与合规范围差异很大，每个合作单独报价。
邮件 [jiekechoo@gmail.com](mailto:jiekechoo@gmail.com) 可获取估算。

**首个正式版本发布前能启动采购或 POC 吗？**
咨询与 POC 沟通现在就可以开始；签署的商业条款与 SLA 随首个 tag 版本生效。

**概念验证（POC）免费吗？**
不自动免费。使用社区版自行评估，任何时候都免费；由厂商执行的私有 POC——在你的
现场或针对你的环境做的定制工作——属于商业合作：视范围可能单独收费、打包进订阅，
或在后续签约时抵扣。具体方式一律事先书面约定。

**NereidFactory、NereidSentinel、NereidMedical 怎么算？**
它们是构建在开放平台之上的商业行业解决方案，各自按独立项目合同交付。见
[商业行业解决方案](../solutions/index.md)。

**你们能帮我们做集成或适配吗？**
可以——厂商执行的定制开发（设备/连接器集成、多厂商芯片/NPU 加速、行业特定适配）
按工作说明书逐项目界定范围、单独报价。基于平台自行扩展在 Apache-2.0 下始终免费。
见[定制开发](../solutions/custom-development.md)。
