# 仪表盘

仪表盘是登录 NereidHorizon 后默认进入的页面，用于快速了解系统整体状态：确认管理中心是否健康，并直接进入日常运维操作。Horizon 仪表盘上的所有数据均来自 Exchange API，每 30 秒自动刷新一次。

## 页面内容

- **系统信息卡片（System Info）**：显示 Exchange 版本、BFF 服务启动时间与运行时长、当前组织，以及在线节点数。
- **快速操作（Quick Actions）**：以卡片形式提供各功能模块的快捷入口，例如服务、模式、节点等。
- **最近节点活动（Recent Node Activity）**：展示最近有心跳上报的边缘节点，按最后心跳时间倒序排列（最新在前）。

## 使用方法

1. 登录后先在**系统信息卡片**确认 Exchange 版本与当前组织是否符合预期。
2. 查看**在线节点数**，确认边缘节点集群是否已连接。
3. 通过**最近节点活动**发现停止上报心跳的节点。
4. 使用**快速操作**直接打开所需模块，无需逐个查找侧边栏菜单。

## 故障排查

!!! warning "连接失败"
    如果仪表盘显示连接失败，请检查 Exchange URL 是否正确、Horizon 到 Exchange 的网络是否可达，以及登录凭证是否有效。
