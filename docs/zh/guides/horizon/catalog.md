# 目录

目录（Catalog）是 NereidHorizon 中的公开服务与模式的只读浏览器。它展示 Hub 与远程组织发布的内容，方便在不离开控制台的情况下跨组织参考和复用定义。

## 可以做什么

- 浏览 Hub 和其他组织提供的公开**服务**与**模式**。
- 点击任意条目，以 JSON 形式查看其详细信息。

目录为只读视图，仅用于发现和参考。若要创建或修改服务、模式，请使用[服务](services.md)和[部署模式](patterns.md)模块，或在目录中查阅定义后到相应模块导入。

## 浏览目录

1. 打开「目录」页面。
2. 找到需要查看的公开服务或模式。
3. 点击条目查看完整的 JSON 定义。

## 访问错误

| 错误码 | 含义与处理 |
|---|---|
| 402 / 401 | 无权访问该组织的目录，需要先获得相应授权。 |

进行需要高权限凭证的跨组织操作时，可按[协议机器人](agbots.md)页面说明使用「Authorize」操作。
