# 组织

组织（Organization）是 Exchange 中的顶级隔离单元。在 NereidHorizon 中，每个组织拥有独立的服务、模式、节点等资源，因此在一个组织内进行的操作不会影响其他组织。

## 创建组织

必填项：

- **Org ID（组织 ID）**：唯一标识。
- **Label（标签）**：显示名称。

选填项：

- 描述。
- 节点数量上限。
- 心跳间隔。

## 权限

- **Hub Admin** 用户可以创建和删除组织。
- 系统组织（**IBM**）拥有覆盖整个管理中心的全局视图。

在 [BFF 用户](bffUsers.md)中创建合作方账号时，绑定到某个组织的合作方只能操作该组织内的资源。

## 错误码

| 错误码 | 含义 |
|---|---|
| 400 | 组织 ID 缺失 |
| 409 | 组织已存在 |
| 502 | Exchange 不可达 |
