# 边缘节点

边缘节点模块用于管理在 NereidHorizon 中注册到管理中心的边缘节点。在此页面可以查看和搜索节点、设置部署模式、编辑节点策略，并查看协议、错误和管理状态。节点首次接入管理中心的流程见[节点注册](node_registration.md)。

## 第一步：查看节点

列表展示每个节点的 ID、名称、类型、架构、内存、部署方式、已部署服务数、特权开关、最后心跳时间和状态。支持按名称、类型、模式或架构搜索，并支持分页。

## 第二步：设置模式

1. 点击节点行尾的「Set Pattern」按钮。
2. 从下拉列表中选择一个部署模式，模式名称格式为 `org/patternname`。
3. 留空则表示清除模式，改为通过策略部署该节点。

!!! note "模式变更需要授权"
    修改已注册节点的模式需要 `root/root` 授权：点击「Authorize」并输入 root 密码。修改后必须在节点上重新注册才能生效，Horizon 会在界面上生成相应命令。

## 第三步：查看详情

点击「View」打开详情抽屉，共 5 个标签页：

| 标签页 | 内容 |
|---|---|
| Info | 基本信息以及可编辑的节点策略 |
| Services | 已注册和已部署的服务，以及对应的协议 ID |
| Agreements | 该节点当前达成的所有协议 |
| Errors | 节点错误历史记录 |
| Mgmt Status | 管理策略（NMP）的执行状态 |

## 第四步：编辑节点策略

- 系统属性（`openhorizon.*`）只读，不可修改。
- 以 `Name=Value` 形式添加自定义**属性（Properties）**，例如 `gpu=true`。
- 添加**约束（Constraints）**，每行一条，例如 `openhorizon.allowPrivileged == true`。
- **allowPrivileged** 开关控制是否允许特权容器，修改后约 60 秒自动生效。

## 错误码

| 错误码 | 含义 | 处理方式 |
|---|---|---|
| 401 | 未授权 | 重新登录或提供 root 授权 |
| 400 | 请求参数错误 | 修正参数，例如模式格式不正确 |
| 502 | Exchange 连接失败 | 检查 Exchange URL 与网络 |
