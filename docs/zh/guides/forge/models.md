# 模型库

模型库是所有模型版本注册、对比与部署的地方。训练好的模型会自动入库，外部权重也可手动上传。

## 流程

1. **模型注册**：训练完成后自动注册，也可手动上传（`.pt` / `.onnx`）。
2. **版本管理**：每个模型拥有多个版本，优化版本带有目标设备与加速比信息。
3. **对比选型**：版本表显示目标设备 / 加速比，据此选择最优版本。
4. **部署**：选择版本 → 配置运行时（OpenVINO / Triton）+ GPU + 域名 → 自动创建 KServe 服务与 Ingress。

## 前提条件

- 手动上传需 `.pt` / `.onnx` / `.tflite` 等模型文件。
- 部署域名需可在 DNS 解析；默认生成 `<模型>-<版本>.inference.<平台域名>`。

## 常见问题

!!! question "部署后怎么访问？"

    部署响应返回域名；Ingress 自动创建，DNS 指向集群 IP。

!!! question "运行时选哪个？"

    OpenVINO（CPU，已验证）或 Triton（GPU 场景预留）。
