# 数据集

数据集是 Forge 所有工作流的起点：上传图片、每次上传保留为一个版本，之后即可基于该版本进行标注或训练。

## 流程

1. **创建数据集**：填写名称与描述，选择格式（COCO / YOLO）。
2. **上传数据**：支持单张图片或 ZIP 压缩包，压缩包异步解压入库，可在 Dataset Versions（数据集版本）页查看进度。
3. **使用版本**：每次上传都会生成一个新版本，历史版本保留，可随时切换。

## 前提条件

- 数据集图片格式支持 jpg / jpeg / png。
- ZIP 内图片放在根目录或 `images/` 子目录均可。

## 常见问题

!!! question "如何准备标注训练数据？"

    在标注工作台完成标注后，通过“导出”生成 YOLO 格式，训练会自动读取。

!!! question "版本号怎么递增？"

    每次上传图片都会自动创建新版本。
