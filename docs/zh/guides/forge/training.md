# 模型训练

训练基于某个数据集版本运行真实的 Kubeflow Pipelines（KFP）流水线，并把结果注册为模型库中的新模型版本。

## 流程

1. **创建训练任务**：选择数据集（版本）+ 模型基座 + 超参数。
2. **填写结构化表单**：建议默认值见下表。
3. **启动运行**：平台自动切分 train/val，运行 KFP 流水线（真实训练）。
4. **产出结果**：完成后自动注册模型版本到模型库，并生成训练曲线。

| 参数 | 建议值 |
|---|---|
| 模型基座 | YOLOv8n |
| epochs | 100 |
| imgsz | 640 |
| batch | 16 |
| train/val 比例 | 0.8 |

## 前提条件

- 数据集需为 YOLO 格式：标注导出会自动满足；原始 COCO 会自动生成 `data.yaml`。
- 训练资源（CPU/GPU）由集群自动匹配；无 GPU 时使用 CPU。

## 常见问题

!!! question "曲线在哪看？"

    任务详情页的“训练曲线”Tab。

!!! question "中断了怎么办？"

    失败任务可重新启动；断点续训支持从 checkpoint 恢复。
