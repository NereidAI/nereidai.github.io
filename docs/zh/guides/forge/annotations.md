# 标注

标注把图片数据集转化为带标签的训练数据。Forge 内嵌 Label Studio 作为标注工作台，并支持通过 ML Backend 进行半自动标注。

## 流程

1. **创建标注项目**：选择数据集 + 标注任务类型（检测 / 分割 / 分类等）。
2. **打开标注工作台**：工作台内嵌 Label Studio，逐图标注矩形框、多边形等。
3. **半自动标注**：点击“半自动标注”，可选择 ML Backend（模型）对未标注任务进行预标注。
4. **审核导出**：标注完成后可导出为 COCO / YOLO / Label Studio JSON / CSV。

## 前提条件

- 需要已上传图片的数据集。
- 半自动标注需要可用的 ML Backend（在 ML Backend 页注册，或使用默认服务），参见 [ML Backend](mlbackend.md)。

## 常见问题

!!! question "预标注没结果？"

    确认所选模型的类别与标注配置一致；弱模型置信度低属正常现象。

!!! question "导出到哪？"

    导出生成新数据集（YOLO 格式），训练页可直接选择。
