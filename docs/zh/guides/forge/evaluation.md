# 模型评估

评估让模型版本在数据集上打分并给出真实指标，帮助判断该版本可以直接部署，还是需要再做一轮优化。

## 流程

1. **创建评估任务**：选择模型（版本）+ 数据集。
2. **调整参数**：置信度阈值、最大图片数、任务类型（建议默认值见下表）。
3. **选择数据**：默认使用训练产出的 val 子集；也可选任意数据集版本（自动转换为 YOLO）。
4. **查看指标**：完成后显示真实指标：mAP50 / Precision / Recall / F1 / 延迟。

| 参数 | 建议值 |
|---|---|
| 置信度阈值 | 0.25 |
| 最大图片数 | 0（全部） |

## 前提条件

- 模型需有 ONNX 产物。
- 数据集需可解析为 YOLO（自动处理）。

## 常见问题

!!! question "为什么 precision 是 0？"

    模型未收敛，或阈值过高导致预测数量过少；调低置信度阈值后重试。

!!! question "评估数据用哪份？"

    默认使用训练 val 子集，避免数据泄漏。

## 下一步
