# 快速开始

NereidForge（Forge）是 NereidAI 套件中的私有化**模型工厂**——一条把业务图片变成现场可用模型的生产线：准备数据集 → 标注 → 训练 → 优化与量化 → 评估 → 注册与部署，全程运行在本地环境内、可完全离线运转。完整能力概览见[产品介绍](../../products/nereidforge.md)。

本指南带一个模型走完它在工厂中的第一次完整流转。

## 流程总览

| 步骤 | 页面 | 产出 |
|---|---|---|
| 1. 准备数据 | [数据集](datasets.md) | 创建数据集、上传图片或 ZIP，得到版本化数据集 |
| 2. 标注 | [标注](annotations.md) · [ML Backend](mlbackend.md) | 完成标注（可用模型预标注），导出 YOLO |
| 3. 训练 | [训练](training.md) | 选数据集版本 + 模型基座 + 超参数，跑 KFP 流水线 |
| 4. 优化 | [优化](optimization.md) | 面向目标设备做 ONNX 图优化 + int8 量化 |
| 5. 评估 | [评估](evaluation.md) | 得到 mAP50 / Precision / Recall / F1 / 延迟 |
| 6. 注册与部署 | [模型](models.md) | 选择版本、配置运行时，创建 KServe 服务 |

## 1. 准备数据集

在数据集页创建数据集（COCO / YOLO），上传 jpg / jpeg / png 图片或 ZIP——图片放在压缩包根目录或 `images/` 目录均可。ZIP 会异步解压入库，每次上传都会生成并保留一个新版本。

## 2. 标注

在标注页创建标注项目，在内嵌的 Label Studio 工作台逐图标注（检测 / 分割 / 分类）。想提速时，可通过 ML Backend 页注册的 ML Backend 进行半自动标注。完成后导出为 YOLO——导出会生成一个可直接用于训练的新数据集。

## 3. 训练

在训练页选择数据集版本、模型基座（建议 YOLOv8n）与超参数（建议 epochs 100、imgsz 640、batch 16、train/val 比例 0.8）。集群自动匹配 CPU/GPU 并运行真实的 KFP 流水线；完成后模型自动注册，并可查看训练曲线。

## 4. 优化与量化

在优化页选择源模型和一个或多个目标设备（CPU / OpenVINO / NVIDIA 等）。每个目标独立执行 ONNX 图优化与 int8 量化，产物落入 SeaweedFS 并注册为新版本，带有真实的加速比与体积缩减指标；缺少对应硬件的目标保持 pending。

## 5. 评估

在评估页对版本打分——默认使用训练 val 子集，以避免数据泄漏。查看 mAP50 / Precision / Recall / F1 / 延迟，并关注优化版本的 `accuracy_drop`。若 precision 为 0，可调低置信度阈值（建议 0.25）后重试。

## 6. 注册与部署

训练版与优化版都在模型库（模型页）中，版本表可对比目标设备与加速比。选择版本，配置运行时（CPU 用 OpenVINO，GPU 场景预留 Triton）、GPU 与域名，Forge 会创建 KServe 服务与 Ingress；部署响应返回端点域名。

!!! tip "循环往复"

    现场数据可以开启新一轮：作为新数据集版本重新上传、补充标注、重新训练与评估。每个模型版本都保留其数据、指标与部署历史。
