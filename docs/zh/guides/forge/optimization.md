# 模型优化

优化把训练好的模型针对一个或多个目标设备进行编译与量化。每个目标生成独立任务，产物携带真实 benchmark 指标注册为新模型版本。

## 流程

1. **创建优化任务**：选择源模型（版本）+ 一个或多个目标设备。
2. **多目标**：可选择多个设备（CPU / OpenVINO / NVIDIA 等），每个目标生成独立任务。
3. **自动处理**：平台自动完成 ONNX 图优化 + int8 量化，产物落入 SeaweedFS，并注册为带目标后缀的新模型版本。
4. **对比选型**：优化版本带有加速比、体积缩减等真实指标，可在模型库中对比选型。

## 前提条件

- 源模型需有 ONNX 产物（训练产出或手动上传的 `.onnx`）。
- NVIDIA / TensorRT 等目标需要对应的硬件 / 工具链；集群无硬件时任务标记为 pending。

## 常见问题

!!! question "加速比从哪来？"

    由 `optimize.py` 使用 ONNX Runtime 做真实 benchmark 得到，并非估算值。

!!! question "优化后怎么用？"

    优化版本注册在源模型下，可部署、可评估。
