# 账号管理

**账号**页面（用户菜单 → 账号）用于在 NereidSphere 内管理套件账号。该页面仅在
OIDC 模式下可用，并要求具备以下套件角色之一：

- **管理员**——查看与管理账号；
- **运维人员**——查看账号（只读）；
- **普通用户**——不能访问账号控制台。

管理员无需登录身份引擎自带的管理控制台。NereidSphere 使用
`nereidsphere-admin` 服务账号执行经过收敛的账号生命周期操作。

## 搜索与分页

可通过用户名、显示名或邮箱搜索账号。搜索由身份服务执行，并按服务端分页返回。
切换页码或每页数量时会重新向身份服务查询，不会只操作浏览器当前已加载的记录。

## 账号操作

管理员可以：

- 创建本地账号，包括用户名、可选邮箱、显示名、初始密码和套件角色；
- 编辑邮箱和显示名；
- 启用或停用账号；
- 重置密码；
- 分配“普通用户”“运维人员”“管理员”角色；
- 永久删除账号。

新建账号和重置密码默认标记为临时密码，用户下次登录时必须修改密码。如果账号
可能存在审计历史或业务数据归属，建议优先停用；仅当需要彻底清除账号时再使用
永久删除。

角色变更在用户下次刷新令牌后生效；停用账号会阻止新的登录。

## 产品租户与角色

在 OIDC 模式下，创建与编辑账号的对话框还可以为每个套件产品分配租户和角色。
每条分配都会保存为身份服务中以 `/nereid{product}/{tenant}/{role}` 命名的用户组
（例如 `/nereidlink/tenant-a/admins`），各产品可用自己的配置把用户组映射为角色。
不遵循该约定的产品不会出现在选择器中。

租户列表在运行时通过网关从各产品加载，因此租户始终由产品自身维护；如果产品
未提供列表，也可以直接输入租户 ID。分配是增量且幂等的：只会添加或移除与当前
状态不同的用户组。外部账号仍然只读。

## 安全保护

NereidSphere 会防止管理员把自己锁在系统外：

- 管理员不能删除或停用自己的账号；
- 管理员不能移除自己的管理员角色；
- 最后一个启用中的管理员不能被停用、删除或降级。

高影响和破坏性操作需要在界面中确认。删除账号还必须手动输入用户名。

## 邮箱状态

邮箱列显示身份服务中该邮箱是否已验证。NereidSphere 不会根据邮箱格式猜测验证
状态。外部账号显示其身份提供商提供的验证状态。

## 外部账号只读

由外部身份提供商提供的账号会显示提供商别名和“外部账号”标记。其密码、启用状态、
资料和角色必须在对应提供商中管理。NereidSphere 会以
`FEDERATED_READ_ONLY` 拒绝修改请求。

参见[连接状态](connection-status.md)与
[身份提供方](glossary/identity-provider.md)。
