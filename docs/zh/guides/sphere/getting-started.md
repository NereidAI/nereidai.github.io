# NereidSphere 入门

NereidSphere 是轻量套件层：统一门户、单点登录（SSO）入口与统一 API 网关，
自身不含产品业务逻辑。本篇带运维人员走完第一次使用流程——打开门户、登录、
进入已集成产品、管理账号，然后退出登录。

!!! tip "可选，而非必需"
    每个产品都能用自己的登录独立运行。只有当你希望全套件共用一个门户、一次
    登录时，才需要 Sphere 与 Identity。Edge 从不作为中心门户入口——它在每个
    边缘站点独立运行。

## 前提条件

- 一个已部署的 Sphere 实例及其门户地址。
- 默认 OIDC 模式下，Identity 服务可达，且管理员已在套件领域中为你分配账号。
- 一个或多个浏览器可访问的已集成产品（Forge、Horizon、Link）。

## 1. 打开门户并登录

1. 浏览器打开 Sphere 门户；未登录访问会进入登录页。
2. 默认 OIDC 模式下，点击**使用 NereidIdentity 登录**，浏览器经授权码 + PKCE
   流程跳转到 Identity；在该页面输入组织账号密码，Sphere 不会接触密码。
3. 返回后 Sphere 建立加密的 `ns_session` Cookie 并进入门户。应急
   `auth.mode=local` 部署下，则使用明确标注为**应急登录**的表单。

完整流程与错误提示见[登录](sso-login.md)。

## 2. 浏览门户

产品卡片按闭环顺序列出已集成产品——Forge → Horizon → Link——登录后还会显示
你的显示名与套件角色。详见[NereidSphere 总览](portal-overview.md)。

## 3. 进入产品

1. 点击产品卡片；门户始终通过 `/auth/enter/{product}` 进入。
2. 默认票据模式（`ns`）下，Sphere 签发一张 30 秒有效、一次性、绑定受众的
   密封票据；产品在服务端换取已验证身份并建立自己的会话，无需再次登录。
3. 直接 OIDC 模式（`oidc`）下，产品本身就是 Identity 客户端，借助既有 SSO
   会话即可免登进入。

详见[通过单点登录打开产品](product-sso.md)。登录后跳转只接受已配置的精确产品
来源，以防止开放重定向。

## 4. 管理账号（管理员）

打开用户菜单 → **账号**（仅 OIDC 模式可用）。管理员可以创建账号、重置密码、
启用或停用用户、分配“普通用户/运维人员/管理员”套件角色，并为每个账号设置
各产品的租户与角色。运维人员为只读访问；来自外部提供商的联邦账号在此只读，
必须在对应提供商中管理。Sphere 从不使用身份引擎自带的主控台。详见
[账号管理](admin-users.md)。

## 5. 退出登录

打开头部右上角头像中的用户菜单，选择**退出登录**。Sphere 会清除会话 Cookie，
OIDC 模式下随后跳转 Identity 登出页，完成后回到门户。已建立本地会话的产品
可能仍需在产品侧另行退出。详见[会话与登出](session-and-logout.md)。

## 常见问题

登录循环、跳转被拒、每次请求都显示未登录，通常是 Sphere 与产品的模式不一致、
跳转来源未注册或 Cookie 被阻止。先看[常见问题](troubleshooting.md)。
