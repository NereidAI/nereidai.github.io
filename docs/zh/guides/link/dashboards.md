# 仪表盘

仪表盘是由若干组件组成的已保存网格，实时读取平台数据。组件通过与控制台其余部分
相同的 WebSocket 连接取数，不做轮询。

## 管理仪表盘

每行显示名称、组件数量和操作：

- **新建仪表盘** — 创建一个空仪表盘。
- **编辑布局** — 打开布局编辑器：添加、移动、调整组件尺寸，然后保存。保存后的
  布局与仪表盘一起存储。
- **重命名** — 修改显示名称；同一租户内名称必须唯一。
- **删除** — 删除仪表盘及其布局。

## 组件类型

- **时序曲线** — 绘制某台设备（或跨设备聚合）的某个[测点](glossary/telemetry.md)键在所选时间窗口内的曲线。
- **最新值** — 以单个数字显示某测点键的最新值。
- **告警列表** — 展示最近告警，操作员无需离开仪表盘即可看到事件。

## 配置组件

每个组件都可设置标题；数据类组件还需选择设备（不绑定表示全部设备）、测点键，
曲线还需设置时间窗口。没有数据的测点会渲染为空，不会报错。

仪表盘通过服务端推送发送到所有已连接会话，修改后无需刷新即可看到。
