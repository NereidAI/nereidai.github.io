# 边缘密钥类型

**边缘密钥类型**标签（位于**边缘密钥**页内）用于管理平台下发给网关的凭据（[边缘密钥](glossary/edge-secret.md)）描述符。描述符只声明一种凭据包含哪些字段——平台本身不认识任何凭据协议。

## 描述符内容

- **类型键**——网关所理解的凭据类型标识。
- **版本**——可选的描述符版本，留空表示不区分版本。
- **英文名 / 中文名**——双语显示名。
- **字段 schema**——凭据文档的 draft 2020-12 JSON Schema，控制台据此渲染密钥表单。

## 两种来源

- **网关广告**——网关在 hello 中广告描述符，按租户注册且只读；每次连接重新注册，保持目录最新。
- **人工创建**——租户自定义描述符，完整 CRUD。适用于不广告的网关；也可对网关广告的描述符点 **克隆为私有** 后再编辑副本。

## 两种编写方式

- **字段构建器**——逐行添加：字段键、控件类型（文本、密码、整数、数字、开关、下拉）、双语标签、是否必填，下拉字段再填逗号分隔的可选项；构建器自动生成 JSON Schema。编辑人工描述符时，已保存的字段会回填到构建器。
- **JSON Schema**——直接粘贴或编辑完整 schema。

眼睛图标以只读方式**查看**描述符：字段概览表（字段键、类型、必填、显示名）。网关广告的描述符可在此点 **克隆为私有** 创建可编辑副本；人工描述符可点概览表上的 **编辑** 直接进入编辑。铅笔图标（仅人工条目）直接以编辑模式打开。

未注册的类型始终可用自由键值对表单录入。
