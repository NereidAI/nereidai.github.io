# 设备详情

设备详情页展示关于单台设备的全部信息。

## 头部

- 规范名称、设备 ID、配置 ID 和当前[连接状态](glossary/presence.md)。设备设置了别名时，页头副标题显示别名而非 ID。
- 摘要面板展示该设备的全部绑定关系：
  - **客户** —— 归属[客户](customers.md)，为空表示未分配；名称链接到客户管理页。
  - **设备组** —— 该设备所属的唯一设备组（设备组为树形结构，可挂靠到某个客户）；链接到按该组过滤的设备列表。
  - **规则链** —— 实际对本设备生效的规则链组，按优先级解析：设备绑定 → Profile 绑定 → 租户默认组。来源标签标明绑定出处；版本标签显示激活版本，若解析出的链组没有激活版本则显示**无激活版本**警告；名称打开规则链编辑器。
  - **配置 ID** —— 链接到绑定的配置。
  点击页头的**编辑**按钮可在设备表单抽屉中修改以上任一绑定。
- 摘要面板还展示**附加信息**，以及**创建时间**和**最后活动**时间（最新[遥测](glossary/telemetry.md)或 presence 边界中较新者）。别名仅在页头副标题显示，不在面板中重复。
- [子设备](glossary/subdevice.md)摘要中会出现一行**[连接器](glossary/connector.md)**：显示绑定的唯一连接器实例及其上报状态，点击可跳转到所属[网关](glossary/gateway.md)详情的**连接器**页签；网关设备则显示该网关上的网关级连接器实例数量徽标。
- 状态徽标反映最近一次在线状态事件（在线/离线/未知）。

## 选项卡

### 遥测

通过 WebSocket 推送的实时遥测。选择测点键可只关注单个测点。历史值通过遥测历史查询加载。**全部测点**表格会显示每个值的质量标记（`GOOD`、`UNCERTAIN` 或 `BAD`）；含义见"配置"分组下的**数据质量**帮助主题。

形如 `blob://...` 的字符串值引用设备上传的媒体对象（见直连设备集成）。表格按对象声明类型渲染：图片缩略图（点击放大）、播放按钮打开视频播放器、文本/JSON/XML 用文本查看器（内联显示前 256 KiB），其他二进制则显示下载按钮。对象通过短时效签名 URL 访问；对象已被删除时单元格显示"对象已不存在"。

### 属性

属性是按设备保存的相对静态键/值元数据，适合放安装位置、业务分组、采集间隔、功能开关等少量配置。它与高频变化的遥测、以及带期望/上报版本对账的影子不同：平台只负责可靠存储和同步，属性值如何被边缘业务使用由 NereidEdge/固件决定。

三种作用域：

- **CLIENT（客户端）**：设备或规则链写入的设备自有数据。控制台只读展示，不能新增、编辑或删除。
- **SHARED_SCOPE（共享）**：平台写入，并通过 MQTT 推送给在线设备/网关；设备重连后也会主动拉取。需要边缘读取并生效的配置应使用此作用域。
- **SERVER_SCOPE（服务端）**：平台写入的平台侧属性。

> **当前版本的作用域语义请注意：** NereidLink 目前会把 **SERVER_SCOPE 与 SHARED_SCOPE 都下发给设备**（实时 `attributes/down|push` 与重连后的 `attributes/get` 均返回两者）。这与经典 ThingsBoard 模型不同——经典模型中 SERVER_SCOPE 仅平台可见、SHARED_SCOPE 才对设备可见。因此当前不要把 SERVER_SCOPE 当作“设备不可见的私有数据”；需要边缘使用的配置请统一使用 SHARED_SCOPE。对网关代理的子设备，平台属性还会镜像到 EdgeX 设备 Tags；同一键在两个作用域都存在时，以 SHARED_SCOPE 的值为准。

可添加或编辑任意合法 JSON 值的 SERVER_SCOPE/SHARED_SCOPE 属性。操作列提供编辑和删除；删除会立即从平台移除，并向在线边缘下发值为 JSON `null` 的变更，边缘据此删除本地缓存键。表格通过 WebSocket 实时更新：其他操作员会话的修改、删除或设备上报的 CLIENT 属性无需刷新即立即显示。

### 影子

该设备的期望状态与上报状态对比，并可写入期望状态。视图通过 WebSocket 实时更新：来自其他操作员会话的期望状态修改和设备上报状态无需刷新即立即显示。详见"设备"分组下的**设备影子**帮助主题。

### 凭据

该设备持有的全部凭据，包括类型、有效期窗口和状态，以及创建、轮换、停用和吊销操作。详见"设备"分组下的**设备凭据**帮助主题。

### 命令

设备命令目录（白名单）与命令历史。只有已声明的命令可以下发，未声明的命令名会被拒绝。
每个目录条目记录交互方式（one-way/request-response）、时效、默认超时、启用开关和允许方向
（读/写）；标记为「自动（profile）」的条目由绑定 profile 的测点自动物化，一经手工编辑即
转为手工来源。发送时选择命令（绑定 profile 的测点会显示其读/写掩码），再选择读或写
（选项受目录掩码约束），并始终检查 JSON 参数框（默认 `{}`；读命令也可以携带查询参数）。
没有目录条目的 profile 测点可在发送抽屉中内联声明。历史显示方向与状态；点开一行可查看
参数、响应与错误。

### 告警

本设备的告警审计行，包含类型、严重程度、状态和时间戳。

### 连接器与密钥（仅子设备）

网关托管子设备的只读视图，展示其连接所依赖的两个平台能力。**绑定连接器**显示绑定到该子设备的唯一连接器实例（从所属网关的连接器集合中按设备匹配）：类型与版本、上报的生效状态（悬停查看原因）、期望/上报版本号与最近上报时间。**密钥投递**列出所属网关持有的全部密钥绑定——密钥、类型、目标选择子与状态——并注明选择子是由边缘解释的开放 `{kind, value}` 键值对，因此某条绑定是否适用于本设备由边缘判定。两节均链接到所属网关的**连接器**与**密钥**页签，投递管理在那里进行。该页签仅为子设备显示；详见"设备"分组下的**连接器**与**边缘密钥**帮助主题。

### 固件升级（仅直连设备）

仅对直连设备显示（非网关，也非网关托管的子设备）。按时间倒序列出所有以该设备为目标的固件升级：目标版本、设备当前阶段、进度条、所属升级任务的聚合状态与创建时间。点击**时间线**可查看只增不改的阶段历史，含结构化结果码及每个阶段的上报来源。**升级此设备**发起单设备升级——目标锁定为本设备；选择平台托管固件包或填写外部 URL，并选择成功判定策略。直连设备通过轮询鉴权端点发现任务，并经鉴权中继下载固件包。全舰队升级以及任务级暂停/取消在**升级任务**页进行；详见"运维"分组下的 **OTA 任务**帮助主题。

### 托管设备（仅网关）

由本网关注明在线状态的子设备。仅网关设备显示此页签。每行链接到子设备，名称下方显示别名，并列出其配置（链接到配置详情）、绑定的连接器（链接到本网关的连接器页签）、连接状态（悬停显示最后活动时间）和生命周期状态。搜索框可按名称、别名或设备 ID 匹配。

### 连接器（仅网关）

运行在本网关上的协议连接器实例，以期望/上报规格方式管理并提供漂移对账。仅网关设备显示此页签；详见"设备"分组下的**连接器**帮助主题。

### 链路健康（仅网关）

本网关链路中断的历史记录，按时间区间呈现 —— 每次掉线从何时开始、持续多久，以及是租约检测器还是边缘看门狗发现的。仅网关设备显示此页签；详见[链路健康](link-health.md)帮助主题。

### 密钥（仅网关）

下发到本网关的边缘密钥（保险库引用）及每条绑定的投递状态，包括边缘注册的密钥类型。仅网关设备显示此页签；详见[边缘密钥](edge-secrets.md)与[边缘密钥类型](edge-secret-types.md)帮助主题。

### Edge 配置（仅网关）

本网关通过 MQTT 上报的设备配置，按网关缓存，支持查看内容以及纳管/同步到配置库。仅网关设备显示此页签；详见 [Edge 配置](edge-profiles.md)帮助主题。

### 操作（仅网关）

本网关固件在最近一次 hello 中广告的远程操作（及租户自定义描述符），可在此发起调用：按 schema 生成参数、风险分级控制，并保留每次调用历史。仅网关设备显示此页签；详见[网关操作](gateway-operations.md)帮助主题。

## 隔离

被隔离的设备会显示 `QUARANTINED` 徽标、隔离时间和原因，并提供解除操作。详见"设备"分组下的[隔离](quarantine.md)帮助主题。
