# 升级链

升级链页面用于定义告警未及时处理时的通知对象。

## 链结构

一条链包含一组有序步骤。每个步骤定义：

- **延迟（秒）** — 从告警开始起算，经过该秒数后触发步骤。
- **通知角色** — 接收通知的租户角色（`TENANT_ADMIN`、`ENGINEER`、`CUSTOMER_USER`、`READ_ONLY`）。
- **通知设备组** — 可选的设备组；选择后仅通知数据范围覆盖该组子树的角色成员。留空则通知租户内该角色的全部成员。
- **确认后停止** / **清除后停止** — 若告警在延迟到期前被确认或清除，则取消该步骤。

## 升级如何触发

后台进程每 10 秒检查一次。每个到期步骤只触发一次：发送已配置的 Webhook、向目标角色成员发送邮件，并记录站内通知。若步骤指定了设备组，则只向数据范围覆盖该组子树的角色成员发送邮件。编辑升级链不会影响已经触发的步骤。

## 绑定升级链

打开规则链编辑器，选中 **创建告警** 节点，在其配置中选择升级链。该节点产生的告警随后按所选链执行。
