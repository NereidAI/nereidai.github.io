# 设备凭据

设备详情页的**凭据**标签页管理设备如何证明身份。**设备至少持有一个有效凭据前无法连接。**

## 凭据类型

每种类型以不同方式证明"持有"，类型在创建时固定：

| 类型 | 如何证明持有 | 典型用途 |
| --- | --- | --- |
| `TOKEN` | 随机共享密钥，以恒定时间比较。 | 模拟器和简单脚本。 |
| `PASSWORD` | 以 argon2id 哈希存储的密码。 | 本身使用用户名/密码的设备。 |
| `JWT` | 签名的 JSON Web Token；每次连接都会校验签发者、主题和受众。 | 已有身份提供方的设备集群。 |
| `X509` | 在 mTLS 层出示客户端证书；注册的证书必须与出示的叶证书完全一致。 | 使用自有 CA 证书证书的生产设备。 |

密钥是**只写**的。新创建的密钥仅显示一次，之后无法找回 —— 已存储的密码是 argon2id 哈希，按设计明文不可还原。请在创建时妥善复制保存。

## 凭据 ID

添加凭据时，**凭据 ID** 会根据设备的技术规范名与凭据类型预填：`<规范名>_token`、`_password`、`_cert` 或 `_jwt`（例如 `dev-a3f9k2x7_token`）。在你手动编辑该字段之前，切换类型会重新派生 ID；手动编辑后保留你的输入。你始终可以改成任意非空、在本设备上不重复的 ID（它在整个平台范围内也是唯一的）。对于 X.509 凭据，该 ID 同时用作 MQTT 用户名和证书通用名（CN）。

## 有效期窗口

每个凭据都有生效时间和可选的过期时间。只有当凭据为 `ACTIVE` **且**处于有效窗口内**且**设备和租户本身均为活动状态时，才会通过认证。留空表示立即生效且永不过期。

后台巡检器会在凭据临近过期时逐级发出告警，且**每条凭据只对应一个稳定告警**，而不是每个阈值各发一条。

## 带重叠期的轮换

轮换可以在不让设备掉线的前提下更换密钥：

1. 创建新凭据 —— 此时旧凭据仍然有效。
2. 让设备切换到新密钥。
3. 停用或删除旧凭据。

由于重叠期内两者都有效，设备无需在轮换过程中重连。

## 操作

- **启用 / 停用** —— 切换该凭据能否通过认证。停用不等于删除。
- **轮换** —— 为已有凭据签发新密钥。密钥字段留空表示保留原密钥，仅修改有效期窗口。
- **全部吊销** —— 停用该设备的**所有**凭据并结束其在线会话。用于切断你不再信任的设备。
- **删除** —— 移除单个凭据。

## 注意事项

- 凭据被吊销或过期后会**失败即关闭**：不会回退尝试其他凭据。
- 停用凭据本身不会断开连接；如果还要踢掉在线会话，请使用**全部吊销**。
