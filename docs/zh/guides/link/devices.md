# 设备

设备页面列出租户内所有已注册设备及其[连接状态](glossary/presence.md)。设备**永不物理删除** —— 详见下方[停用而非删除](#停用而非删除)。

## 查找设备

- 在搜索框输入内容可按规范名称或别名过滤（在服务端完成过滤）。
- 使用下拉框按表格列的顺序缩小范围：**类型**（[网关](glossary/gateway.md) / [子设备](glossary/subdevice.md) / 独立设备）、**[设备配置](glossary/profile.md)**、**客户**、**设备分组**、**[生命周期](glossary/lifecycle.md)**和**连接状态**（在线 / 离线 / 未知）。每个下拉框都支持输入搜索，当配置、客户或分组很多时可直接在下拉框内键入关键字过滤，无需滚动。**分组**下拉虽然没有对应的表格列，但予以保留：客户与分组页面会以预选分组深链到设备列表，该下拉既展示当前分组过滤，也用于清除它。
- 列表按设备创建时间倒序排列（最新创建在前）。**创建时间**列显示该创建时间；将鼠标悬停在**连接状态**徽标上可查看该设备的**最后活动**时间（最新[遥测](glossary/telemetry.md)或 presence 边界中较新者；从未有遥测时回退为最近一次连接变化时间）。设置了别名时，别名会显示在规范名称下方。
- **[连接器](glossary/connector.md)**列显示设备的边缘连接器情况：子设备行显示其绑定的唯一一个连接器实例，标签颜色即上报状态（已应用 / 创建中 / 已派发 / 降级 / 失败），悬停可看状态文字，点击标签直接跳转到所属网关详情的**连接器**页签；网关行以数字徽标显示该网关上的**网关级**（不绑定子设备的）连接器实例数量，点击同样跳转到网关连接器页签；无绑定时显示 “-”。连接器类型与状态随边缘上报实时刷新。
- **生命周期状态**下拉默认只显示**在用（ACTIVE）**设备。可选择具体状态进一步收窄；点击清除按钮留空则列出所有设备，包括默认视图隐藏的已停用、已归档墓碑记录。
- **连接状态**下拉按实时连接状态过滤，与生命周期状态互不影响。**未知（Unknown）**表示该设备从未产生过 presence 边界。

## 创建设备

1. 点击**创建设备**。
2. **规范名称**由系统自动生成为技术标识（`dev-a3f9k2x7`，网关为 `gw-k2x7a3f9`）：`dev-`/`gw-` 前缀加随机字母数字后缀，租户内唯一。可点击刷新按钮重新生成。该字段在表单中只读，并作为与边缘侧核对名称的稳定身份。
3. 可选选择设备配置。未指定配置的设备按未转换形式存储数值。
4. 可选项还包括**别名**（显示在规范名称下方的人类可读名称）和**附加信息**（自由文本备注，最多 4096 字符）。这两个字段不承载任何平台语义，规范名称仍是设备身份。
5. 创建后进入设备详情添加凭据；**没有任何有效凭据的设备无法连接**。

## 批量导入

从表格一次导入多台设备。

1. 下载 **XLSX** 或 **CSV** 模板 —— 两者列结构相同。
2. 每行填写一台设备。每行的 `canonical_name` 必填且租户内唯一（批量模板不自动生成名称，只有创建设备表单自动生成）。逐行变化的只有测点/配置相关列；`state` 留空则使用平台默认值。
3. 把文件拖到导入抽屉（或点击选择文件），然后确认。

单文件上限 1000 行、4 MiB。导入结果**逐行**反馈：成功创建的设备，以及失败清单和各自原因。个别坏行不会中断整个文件。

## 编辑

- 编辑表单可修改配置以及可选的**别名**/**附加信息**。规范名称是自动生成的技术标识，不可编辑。保存时别名或备注留空即清除已存值。

## 停用而非删除

删除设备绝不会将其移除。删除操作是**停用（decommission）**的别名，它会：

- 将该设备的凭据**停用**而非删除；
- 保留全部遥测、属性、命令和告警；
- 驱逐 presence 并断开在线会话，设备无法再连接；
- 开启召回窗口（默认 90 天），期间可**重新激活**设备并重新签发凭据。

召回窗口到期后，后台巡检会将设备转入**已归档**状态。归档是生命周期的终点，而不是删除。

可勾选多行，使用**批量停用**执行同样的操作。
