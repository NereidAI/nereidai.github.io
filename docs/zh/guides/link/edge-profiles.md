# Edge 配置

**Edge 配置**页签仅出现在**[网关](glossary/gateway.md)设备**上。它列出该网关通过 MQTT（`v1/gateway/profiles`）上报给 NereidLink 的[设备配置](glossary/profile.md)。NereidLink 既接受厂商中立的测点模型，也接受 EdgeX profile 形状。

## 配置会自动进入配置库

- 网关完成 hello 握手后（以及每次重连时）会自动上报其引用的配置。
- 上报的配置在**首次出现时自动汇入**租户配置库（见**配置**页，来源标记为**边缘**），无需先手动采纳即可被引用。
- 这里的每一行是按网关保存的原始缓存（`name` 与 deviceResource/测点数量，载荷逐字保留）。两个网关上报同名配置会链接到同一个库配置，来源是多对多关系。
- 内容不变的重复上报只会刷新**最近上报**时间（平台自行计算内容 hash，不信任线上传输）。
- 同名但内容变化视为**漂移**：绝不静默覆盖，可在本页用**采纳 → update** 接受该网关的版本。

## 搜索

使用顶部搜索框可按配置名称过滤列表（不区分大小写、支持部分匹配）。过滤在本地完成，可覆盖全部已缓存配置而无需请求后端。

## 查看配置内容

点击某行的**查看**可检查缓存配置。抽屉按上报顺序列出每一个 deviceResource 的名称、值类型、单位、描述，并标记无法建模为标量遥测测点的资源（`Binary`/`Object`/`*Array`、重名或空名称）。

## 采纳 / 同步

采纳现在表示把该网关缓存行解析/链接到库配置：

- 普通**采纳**：把缓存行与已自动入库的同名库配置建立/确认链接（幂等）。
- **覆盖（update）**：在检测到漂移时用该网关上的内容覆盖，刷新边缘所有的规范字段（`type`、`unit`、`read_write`、`address`、范围/默认值）；操作员的标定字段（transform、scale、enum、有效范围）永不被覆盖。
- 边缘删除的测点会被标记为 inactive（不物理删除），以保护历史数据与规则引用。

## 权限

列表与查看需要 `profile:read`；采纳需要 `profile:write`。
