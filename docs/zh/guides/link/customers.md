# 客户与设备分组

客户和设备分组用于在一个租户内组织设备。

## 层级关系

租户 → 客户 → 设备。设备分组是租户或客户下的可选容器。

## 客户

客户是一个组织（例如客户公司），可填写联系人、联系邮箱和外部标识。

- 创建设备或编辑设备时可将其指派给客户；之后也可通过设备生命周期菜单（转移）变更。
- 在本页点击客户名称可查看其名下设备。
- 拥有 CUSTOMER_USER 角色的成员只能看到自己所属客户的设备。

## 设备分组

分组是一组命名的设备集合。分组可归属到某个客户，并可设置父分组形成层级树；不允许出现环。

- 在设备表单中把设备指派到分组。
- 点击分组名称可查看组内设备。
- 分组用于筛选以及后续的批量操作。

## 注意事项

- 一台设备最多归属一个客户和一个分组。
- 仍有设备归属的客户或分组无法删除，请先重新指派设备。
- 未指派的设备仍会显示在完整设备列表中。
