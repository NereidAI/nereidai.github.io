# 统计中心

统计中心提供超出总览 KPI 的详细数字，包含两个选项卡。

## 系统选项卡

时点基础设施指标：

- **Go 运行时** — 运行时长、协程数、堆内存、GC 次数与暂停。
- **PostgreSQL** — 服务端连接数、应用连接池状态、事务总数、缓存命中率、死锁次数。
- **NATS** — 双向消息与字节数、客户端重连次数。
- **JetStream 流** — 存储消息数、序列号范围以及各消费者积压（待确认、已重投递、确认水位）。
- **MQTT Broker** — 类型及已连接客户端数量。

## 业务选项卡

按所选时间范围（最近 1 小时、24 小时或 7 天）统计的租户活动：

- 设备总数及按配置分布。
- 遥测量时间线。
- 告警按状态和严重程度分布；命令按当前状态分布。
- 活跃规则链数量。

## 刷新

两个选项卡均每 30 秒自动刷新。可点击暂停按钮停止自动刷新，或点击刷新按钮立即刷新。

## 供监控系统使用

相同指标以 Prometheus 格式暴露在 `/metrics`。将 Prometheus 指向该端点，并从 `deploy/monitoring/` 导入 Grafana 仪表盘。
