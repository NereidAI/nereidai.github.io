# 规则链

规则链负责路由设备消息并执行租户定义的动作。平台本身不含业务逻辑 — 业务逻辑就在这里。

## 规则链组

一条"规则链"是一个**链组**，组内含多个不可变版本。[设备配置](glossary/profile.md)（Profile）和设备绑定的都是链组，因此激活新版本不会改变绑定关系。

每个租户有且仅有一个**默认链组**，作为未显式绑定时的兜底。

## 绑定与解析顺序

每条消息按以下优先级决定执行哪条链：

1. **设备绑定** — 设备单独设置的链会整体替换其配置链。
2. **配置绑定** — 同一 Profile 的设备共用一条链。
3. **租户默认链组** — 前两级都未绑定时使用。

绑定入口分别在：设备表单（设备级）、Profile 表单（配置级）。

## 版本

每条链按版本不可变：

- **草稿** — 已保存、可编辑的候选版本。
- **活跃** — 当前正在处理消息的唯一版本。
- **已归档** — 被取代或停用的版本。

编辑永远不会修改某个版本；保存会创建新草稿。激活某个版本会以原子方式归档同组先前的活跃版本。

## 使用规则链

- 点击 **新建规则链** 创建链组，随后会自动打开编辑器构建图。
- 当链组的最新版本是草稿时，可点击 **激活** 使其生效。活跃版本在列表中有标记。

## 删除规则链

只有**既不是租户默认链组、也没有被任何设备或设备配置绑定**的链组才能删除。否则删除按钮置灰，悬停可查看当前绑定的设备/配置数量。删除前请先为引用它的设备或配置解绑（未显式绑定时会按解析顺序回退）。删除会永久移除该链组的所有版本。

如何构建图请参阅"规则链编辑器"帮助。
