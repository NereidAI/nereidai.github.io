# 边缘密钥

**边缘密钥**页是租户用于存放平台下发给网关的凭据（[边缘密钥](glossary/edge-secret.md)）的密码本。页面包含两个标签：**密钥**（密码本，本页）与**类型**（[密钥类型](edge-secret-types.md)描述符）。值只写：列表和详情只显示元数据（名称、形态、类型、时间），不显示内容。**密钥**列表支持按名称或类型搜索，并可分页。

## 创建密钥

1. 填写名称——可用于 `secret://` 引用的稳定标识。
2. 选择类型：
   - **类型**标签中已有的描述符，表单按其字段渲染；或
   - **自由键值对**，适用于没有描述符的凭据。逐行填写键/值，并标记该行是否保密；未添加任何行就保存时会提示至少添加一行。
3. 保存。整份文档以 AES-256-GCM 加密（密钥保存在数据库之外）。

## 轮换与删除

- 再次保存即**原地覆盖**，不保留历史版本。
- 普通删除带保护：如果任一网关仍持有未移除副本，删除弹窗会列出这些网关并阻断硬删除。
- **强制删除并撤回**仅限人类账号：在弹窗中发起并验证新的认证器（MFA）质询。平台随后撤回所有网关副本；离线网关的绑定会保持**撤回中**，待其重连并上报**已撤回**。只有最后一个引用消失后，密码本正本才会删除。

## 投递给网关

打开网关详情页的**密钥**页。

1. 点击**投递密钥**，选择一个类型化文档密钥。
2. 可选添加目标选择子——平台永不解释的开放 `{kind, value}` 对照。对接文档约定的第一个 kind 是 **mac**：表示该 secret 绑定到对应 MAC 的设备，“绑定后如何使用”完全由 Edge 自行决定。不填选择子表示整机绑定；一条绑定可含多个选择子，同一目标也可出现在多条绑定中。
3. 保存。网关在线时立即下发期望状态；离线期间保持待投递，下次 hello 时全量幂等重发。

每条绑定显示单调递增的**版本**与状态：

- **待投递**——已录入，尚未写入网关。
- **投递中**——已通过传输发出。
- **已生效**——网关回执成功。
- **失败**——悬停标签查看网关给出的原因。
- **撤回中 / 已撤回**——撤回流程。

当网关最近一次 hello 未协商 `secrets` 能力时，页面显示警告横幅**网关固件不支持密钥投递**。此时可先录入绑定（不会发送），固件升级后自动投递。

**撤回**会使绑定经过**撤回中**到达**已撤回**：网关在下次同步时抹除副本，平台保留密码本正本。表格实时更新，无需轮询。

绑定停留在待投递/投递中超过五分钟会产生警告告警；持续失败一小时后告警由主要升级为严重。

## 旧版单值密钥

早期条目（形态为“单值”，类型化文档之前创建）继续可用，包括以 `secret://<名称>` 引用它们的连接器配置。编辑此类条目仍保持单值形态。
