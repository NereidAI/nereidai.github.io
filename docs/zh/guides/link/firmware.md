# 固件包

固件仓库保存升级任务下发给设备的产物。一个固件包 = 一个二进制文件，加上平台判断
某台设备能否接收它所需的元数据。上传固件包是平台自己提供固件的唯一途径。

## 上传固件包

- **发布名称** — 必填，面向人的发布标题（如“网关传感固件”）。它在列表和任务中
  独立于技术版本号标识本次发布。
- **版本标签** — 显示在设备和任务上的版本字符串（如 `1.4.2`）。自由填写，不做
  顺序解析，但必须与设备刷写后上报的版本一致；平台据此跳过已是目标版本的设备。
- **发布说明** — 可选，描述新增、修复或注意事项。在列表中悬停发布名称可查看。
- **固件文件** — 二进制文件，上传上限 512 MiB。
- **设备型号** — 可选。绑定到某个设备型号，或留空表示型号无关（任何型号都可
  获取）。型号绑定的固件包若被投放到其他型号会被拒绝（400）。
- **标记为推荐稳定版** — 标记为默认推荐版本；每个型号作用域只允许一个稳定版，
  标记新的会自动清除旧的星标。

## 仓库列表

每行显示发布名称与版本（悬停可看发布说明）、文件名、设备型号（或型号无关）、大小、
SHA-256 摘要和上传时间。摘要就是设备下载后校验的依据，可用它确认文件与预期一致。

## 操作

- **标记稳定版 / 取消标记** — 设置或清除推荐稳定版标记。
- **下载** — 获取已存储的产物。
- **删除** — 删除固件包。正在运行的升级任务所引用的固件包无法删除。

## 固件包如何到达设备

设备不会通过管理 API 接收产物。当任务选择平台固件包时，平台授权下载，设备通过
带鉴权的中继流式获取文件，并在应用前校验 SHA-256 摘要。若未配置对象存储，则
无法上传固件包，任务必须使用外部 URL。
