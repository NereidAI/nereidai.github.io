# 部署许可证

部署许可证是厂商签名的离线文件，用于限制本平台可承载的规模。它采用 Ed25519 签名；
平台用已配置的公钥验证签名，绝不会仅凭文件内容就信任它。

## 安装许可证

选择厂商 `.json` 文件（或粘贴内容）并安装。文件包含 base64 载荷与其独立的
Ed25519 签名。安装会立即替换当前许可证；同一文件也可用 `nereidlink license`
命令行安装，因此无需运行控制台即可为部署授权。签名验证失败的许可证会被拒绝，
当前许可证保持不变。

## 字段

- **状态** — 已安装或未安装。
- **客户** — 授权客户。
- **租户上限 / 当前租户数** — 可创建的租户数量；Unlimited 表示不限。
- **签发时间 / 过期时间** — 有效期区间。
- **功能** — 授权的功能集合；为空表示无功能限制。

## 只读降级

当许可证缺失、已过期、超过租户或设备上限，或回滚时钟检测到篡改时，部署会降级为
**只读**，而不是直接停机：

- 不能新建租户、不能新建设备；
- 不接受新的设备连接；
- 已有设备继续上报，已有数据仍可读取和查询。

当部署处于只读状态时，本页会显示提示横幅。导入有效许可证即可恢复完整能力，无需
重建任何数据。
