# 审计链（平台）

**审计**页面展示防篡改审计日志，仅平台管理员可访问。

## 概览

审计事件记录平台中与安全相关的操作。每一行都属于一条**哈希链**：每个事件的哈希由前一个事件的哈希加上本事件的规范化内容计算得出。由于每一行都锚定其前一行，任何篡改或删除都会使其后所有哈希失效。

每条事件包含序号、时间戳、操作者、事件类型、动作、目标资源、来源 IP，以及每行的 `prev_hash`/`hash` 对。

## 筛选

使用筛选项缩小日志范围：
- **事件类型** — 所记录操作的类别
- **租户** — 仅查看某个租户的事件
- **操作者** — 仅查看由特定用户执行的事件

## 校验

点击**校验**对整条链执行完整性检查。校验器会：
1. 按顺序读取全部事件，检查序号是否连续无缺口。
2. 用前序哈希与本行内容重新计算每行的哈希，并与存储的哈希比对。
3. 检查每日的哈希封条（seal）。

结果会报告已检查的事件数、链是否完整；若不完整，还会给出检测到断裂的序号及原因。

## 有什么用

哈希链提供了日志历史未被改写的证据。校验成功说明日志内部一致；校验失败则精确定位到第一行被改动的记录。由于每一行都锚定其前驱，攻击者无法在不被发现的情况下悄悄修改历史事件。
