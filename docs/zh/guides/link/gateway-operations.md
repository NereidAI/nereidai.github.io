# 网关操作

**网关操作**页展示聚合后的操作目录：各网关在 hello 中广告、平台按网关分别存储的描述符，与租户私建操作。平台自身不内置任何操作名，也绝不按名字推断风险——风险只来自描述符。两台网关广告相同键时各自独立保存；页面将其合并为一行，并显示有多少台网关广告（悬停查看名称）。

## 描述符字段

- **操作**——网关所理解的标识键。
- **版本**——可选的描述符版本。
- **交互方式**——请求/响应（等待结果）或单向。
- **风险级**——只读、普通或危险。
- **超时**——执行时限，100–60000 毫秒。
- **英文 / 中文名称与描述**——按操作员界面语言展示，缺失时回退英文，再回退操作键。
- **参数 / 结果 JSON Schema**——调用时控制台据此渲染参数表单与结果视图。参数 schema 可逐字段构建（名称、类型、是否必选、描述），也可用**高级 JSON**直接编辑；含构建器无法表达之约束的 schema 只能用 JSON 模式。

## 目录管理

- 任意一行点眼睛图标可打开**只读详情**：操作键、版本、风险级、交互方式、超时、来源、双语名称/说明以及完整的参数/结果 JSON Schema。
- 广告操作（来源“广告”）只读；可在详情中点 **克隆为私有** 编辑副本，或用启用开关对其禁用。
- 私有操作可查看、编辑、删除。
- 启用开关可对本租户禁用某个操作；被禁用的项仍显示，便于重新启用。

## 查找操作

- 使用搜索框（匹配名称、键、版本、描述）与来源/风险筛选；表格在前端分页。
- 红色**契约冲突**标签表示广告同一“操作+版本”的各网关在风险级、超时或 schema 上不一致。请统一固件版本，或让它们广告不同的键；调用时始终按目标网关自己的副本校验。
- 网关详情的**操作**页签是该网关的权威清单，并提供独立的搜索、风险筛选与分页。

## 在网关上执行

网关详情页的**操作**页只列出该网关固件在最近一次 hello 中广告的操作（以及租户自建描述符）。

- 填写按 schema 渲染的参数。平台在下发前会再次按描述符 schema 校验，绕过控制台校验也无法发送非法参数。参数值可用 `secret://<名称>` 引用密码本中的钥匙；引用只在最后一跳还原，绝不以明文落库。
- **只读**动作直接执行；**普通**动作需要真正的二次确认（点击执行后再在确认气泡中确认）。
- 可用**超时下调**缩短等待（下限 100 毫秒）；绝不能超过描述符默认值，超出范围会被钳制到 100–60000 毫秒。
- 所有操作仅限人类身份：机器（服务账号）身份在任何风险级都会被拒绝并返回 `OPERATION_HUMAN_ONLY`。**危险**动作还须在最近五分钟内完成一次全新的动态码（TOTP）step-up。弹窗显示描述操作、网关和过期时间的签名二维码，请核对与预期一致后再输入当前动态码。被拒绝的危险尝试即使未生成任务，也会写入审计日志。
- 结果直接在弹窗展示，每次调用（含失败原因）都会出现在下方的操作历史中。结果保留 90 天；“谁在何时对哪台网关执行了什么”的永久记录在链式审计日志中。
- 网关离线时立即返回**网关离线**，操作绝不排队。需要重连后送达时请使用设备命令。
