# 告警

告警页面是告警生命周期与审计中心。

## 过滤

- **活动** — 当前为 `ACTIVE` 或 `ACK` 的告警。
- 单个状态：`ACTIVE`、`ACK` 或 `CLEARED`。
- 可按设备、严重程度（`CRITICAL`、`MAJOR`、`MINOR`、`WARNING`）、告警类型和指派人（含**未指派**）过滤。
- 所有生效的过滤条件都会反映在 URL 中，便于收藏或分享过滤视图。

## 确认

对活动告警点击 **确认** 可将其标记为已确认。确认时记录确认时间；已确认告警在清除前仍属活动告警。对已确认告警再次执行为空操作。

## 告警如何产生

告警由[规则链](glossary/rule-chain.md)中的 **创建告警** 节点打开。具有相同去重键的重复事件会更新已打开的告警，而不是产生重复告警；清除需使用 **清除告警** 节点。
