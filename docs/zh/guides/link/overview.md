# 总览

总览是租户运维仪表盘，用于一眼回答"现在发生了什么？"。

## KPI 卡片

- **设备** — 已注册设备总数及在线/离线数量。点击卡片进入设备列表。
- **活动告警** — 处于 `ACTIVE` 或 `ACK` 状态的告警。点击进入按活动告警过滤的告警中心。
- **待处理命令** — 尚未进入终态的命令（`PENDING`、`CLAIMED`、`QUEUED`）。
- **未读通知** — 尚未标记已读的站内通知。
- **遥测（1 小时）** — 最近 1 小时收到的数据点；辅助行显示 24 小时总量。

## 面板

- **遥测吞吐量** — 按 5 分钟分桶的数据点数量。
- **按严重程度统计活动告警** — 当前告警分布。
- **最近活动告警 / 在线状态 / 通知** — 最新事件。

## 更新方式

首次加载为一次 REST 快照，之后通过每种资源的通配 WebSocket 订阅更新，没有轮询。可以拖动面板标题栏移动面板、从右下角缩放；布局保存在浏览器本地。
