# 用户与角色

本页管理当前租户的成员账号：创建用户、分配角色、重置凭据、启用/禁用账号以及移除
成员。**平台管理员**可对任意租户打开本页；**租户管理员**只能管理本租户的成员。工程师、
客户用户和只读账号会看到无权访问的提示。

每个成员 = 一个登录身份 + 在本租户中恰好一个成员关系。移除成员即移除其对本租户的
访问权限；仅当该账号在所有租户都没有成员关系时才会删除登录账号本身（经套件 SSO 在
其他租户仍有授权的账号会保留）。

## 角色

角色固定且区分大小写。成员可拥有多个角色，实际权限为各角色权限点的并集。

- **租户管理员（Tenant Admin）** — 租户内全部读写权限，含用户管理；可读取所有
  客户数据，操作可审计。
- **工程师（Engineer）** — 设备配置与命令、设备 Profile、规则链、告警、仪表盘、
  升级链、探测与边缘连接器；无用户管理权限。
- **客户用户（Customer User）** — 查看并命令范围内的设备、确认告警、读取通知与
  仪表盘；无配置权限。
- **只读（Read-only）** — 只读：设备、Profile、规则链、告警、钩子、仪表盘与统计；
  任何内容都不能修改。

权限判定为 权限点 × 资源 × 数据范围。角色提供权限点，成员关系上的数据范围决定
该权限点作用于哪些设备。一个拥有 `device:read` 且数据范围为 CUSTOMER 的客户用户，
只能看到自己客户的设备，而看不到整个租户。

## 数据范围

每个成员关系都带一个数据范围，可在行操作的**数据范围**中修改，创建成员时也可设置：

- **整个租户** — 不做收窄，可触达租户内全部设备。
- **指定客户** — 仅可触达所选客户的设备，请在*范围对象*中选择客户。
- **指定设备分组** — 仅可触达所选分组**及其所有下级分组**的设备，因此把范围设在
  父分组上时，后续新增子分组也不会越界。

范围对象的选择项会随级别切换，因为客户 ID 不能用作分组 ID。“整个租户”不带范围
对象。

不提供 `SELF`（归属于用户本人的资源）：当前数据模型中没有任何资源归属于用户，
该范围无法兑现，提供它只会让请求必然失败。

把范围从客户或分组放大到整个租户，等于授予触达全部设备的权限，因此按权限变更处理：
变更前后的范围都会写入审计日志。

既不属于任何客户、也不属于任何分组的设备，只有*整个租户*范围才能看到。

## 操作

- **新建成员** — 创建登录身份及其成员关系。填写邮箱、可选显示名、可选密码和角色；
  密码留空则由平台生成，且只显示一次。
- **设置角色** — 替换成员的角色集合，至少需要一个角色。
- **数据范围** — 替换成员的数据范围及其范围对象。
- **重置密码** — 设置新密码（留空则自动生成）并清除登录锁定状态；明文只显示一次。
- **启用 / 禁用** — 被禁用的账号无法登录，其会话也失效；禁用可逆。
- **移除** — 删除本租户的成员关系；账号在其他租户再无成员关系时才一并删除。

## 受保护账号

平台管理员账号不能在此修改——角色、数据范围、启用状态、密码和成员关系均不可改。
这可避免最后一名管理员把所有人锁在部署之外。

本页所有操作（创建、设置角色、设置数据范围、重置密码、启用/禁用、移除）都会写入
审计日志。

## 实时更新

成员列表通过 WebSocket `member` 流实时更新：当其他平台管理员新建成员、修改角色或
数据范围、启用/禁用账号或移除成员时，表格会自动刷新，没有也不需要刷新按钮。系统
管理中租户抽屉里的成员列表同样实时，包括查看非本人所属租户的场景。重置密码不改变
列表内容，因此不推送。断线重连后会重新拉取列表，补齐断线期间错过的变更。
