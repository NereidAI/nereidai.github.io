# 租户管理（平台）

**租户管理**页面是平台管理员用于创建和管理租户的控制台，仅平台管理员可访问。租户代表相互隔离的客户环境，每个租户拥有各自的用户、设备、规则链和数据。

## 概览

租户开通任务会经历以下状态：
- `PROVISIONING` — 平台正在创建租户的后台资源
- `ACTIVE` — 租户已完全开通，可以使用
- `SUSPENDED` — 租户已被平台管理员暂停
- `FAILED` — 开通失败；页面会显示最近一次错误

## 操作

- **创建租户** — 开通一个新租户。需填写唯一的租户名称，平台会记录创建人与创建时间。
- **重试** — 重试失败的开通任务，适合在修复外部依赖后使用。
- **暂停** — 暂停一个 `ACTIVE` 租户。租户被暂停后无法登录或执行大多数操作，直到恢复。
- **恢复** — 将 `SUSPENDED` 租户恢复为 `ACTIVE`。
- **成员** — 管理该租户的管理员/成员账号（角色、启用/停用、密码轮换）。

## 成员抽屉

- 通过邮箱/姓名添加成员并分配角色。
- 生成的密码**仅显示一次**，必须立即复制保存。
- 停用/启用成员、编辑角色，均不会删除其审计历史。
- 密码轮换会生成新密码（显示一次）或重新绑定有效期。

## 注意事项

- 暂停是平台级管理手段，**不会删除任何数据**，数据保留策略仍然适用。
- 开通进度记录在租户开通表中，含尝试次数和最近错误，便于排查。
- 所有租户生命周期操作（创建、暂停、恢复、成员变更）都会写入审计事件。
