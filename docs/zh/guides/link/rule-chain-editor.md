# 规则链编辑器

规则链编辑器是用于消息路由的可视化画布。

## 构建规则链

1. 从左侧面板拖动节点到画布。
2. 从节点的输出连接点拖到另一节点以创建边。
3. 点击节点可在右侧抽屉中配置。

## 节点类型

- **脚本过滤** — JavaScript 条件返回 `true` 时放行消息，例如 `return msg.temperature > 30`。
- **路由分支** — 按分支列表路由到命名关系；未匹配的消息走默认关系。
- **转换脚本** — 用返回的对象替换消息。
- **保存属性** — 将脚本返回的属性存入所选作用域。
- **创建告警 / 清除告警** — 按类型、严重程度和可选去重键打开或清除告警。
- **发送命令** — 发布命令，参数由脚本返回。

- **转发（Forward）** — 将消息加入租户[数据转发](forwarders.md)队列，异步投递。

- **日志** — 输出日志行。
## JavaScript 规则

脚本在内置 JavaScript 引擎中运行，必须显式 `return` 值。传入消息为 `msg`，元数据为 `metadata`。

## 测试

输入 JSON 测试数据并点击 **测试投递**。规则链执行但不保存；经过的节点会高亮，失败节点显示错误。可在提交版本前验证逻辑。

## 保存

- **保存新版本** — 将当前图存为新草稿。
- **保存并激活** — 保存并立即生效；先前的活跃版本被归档。

## 实时追踪

使用 **实时追踪** 观察真实遥测数据经过活跃版本。点击后打开底部控制台：

1. 打开 **采集真实消息** 开关。追踪只对当前活跃版本生效；若规则链从未激活，请先激活。
2. 发送真实设备数据（例如用设备模拟器）。
3. 每条消息会出现在左侧列表，显示时间、节点数和错误数。选择一条可在右侧查看按顺序经过的节点路径。
4. 每个节点步骤显示类型、执行耗时和所走的关系；失败步骤以红色显示错误信息，经过的路径会在画布上高亮。
5. 点击步骤上的节点名称可定位到该节点。

采集时控制台会自动刷新。关闭控制台不会停止追踪；如需停止采集，请关闭开关。
