# NereidHorizon

NereidHorizon 是边缘机队的**批量投递站**。在一个控制台里定义"什么软件、什么模型、
跑在哪些现场"，平台就会自动把它们铺到成百上千个网关上——包括完全离线的现场。它是
Open Horizon 管理中枢的图形化运维控制台，让运维人员不必再直接操作原始中枢 API。

当团队面对下面这些现实问题时，Horizon 应运而生：

- "网关遍布几百个地点，靠手工更新已经撑不住了。"
- "其中很多现场是气隙网络，根本没有互联网通道可推送。"
- "每一份部署配置都要求签名，但不可能把签名密钥交给每个运维。"
- "合作伙伴和下级组织需要有限访问权，又不能共享我们的中心凭据。"
- "审计要查谁在什么时候改了哪个节点的什么东西。"

## Horizon 能帮你做什么

### 一块屏幕指挥整支机队的发布

边缘节点、服务定义、部署模式与策略、管理策略、协议机器人、组织与用户，全部在同一个
图形控制台中管理。指定一个服务或模式后，可以一路追踪到真正运行它的节点，节点侧的
环境变量也能就地修改。

### 向没有互联网的现场交付

Horizon 自身可用预制镜像完全离线安装；远端节点上的中枢代理会自主向声明状态对账。
气隙现场享受与联网现场同样的策略化发布，只是按本地网络的节奏完成。

### 永远不用操心签名密钥

Open Horizon 要求每份服务部署配置都必须签名。Horizon 在创建和更新时自动完成签名，
运维人员面对的只是普通表单，加密要求在后台被默默满足。

### 给合作伙伴开门，但不交钥匙

第三方与下级组织拿到的是组织范围内的只读 API 密钥，而非中枢级凭据。两个内置角色
区分跨组织管理员与组织内合作伙伴；单点登录可经
[Sphere](nereidsphere.md) / [Identity](nereididentity.md) 或直接对接 OIDC
提供方完成。

### 任何审计问题都有答案

控制台与 API 密钥的每一个动作都写入只追加审计日志，连实际访问的中枢端点也一并
记录。服务端会话把凭据静态加密存储，加固的 TLS 与安全响应头保护控制台自身。

### 保住关键现场的可用性

高可用节点组让你把冗余边缘节点的成员关系与网络配置统一组织、监控和调整。服务、
模式与策略定义可从 JSON 导入并交互式处理模板变量，还能跨组织浏览公共服务。

## 从一个模型到上千个现场

1. **接收制品**——[NereidForge](nereidforge.md) 构建的模型与应用以带版本的包
   送达。
2. **定义服务**——运维在控制台描述"跑什么、按什么模式或策略跑"；需要重复的定义
   可以 JSON 导入。
3. **自动签名**——保存时 Horizon 自动为部署配置签名。
4. **指派与发布**——中枢的协议机器人与符合条件的边缘节点协商，离线节点会在下次
   联络中枢时完成。
5. **观察与对账**——一路追踪到运行中的节点；配置漂移被自主纠正。
6. **交接给边缘**——[NereidEdge](nereidedge.md) 与
   [NereidInference](nereidinference.md) 在网关上运行起来，开始向
   [Link](nereidlink.md) 回传数据。

## 在套件中的位置

Horizon 占据闭环中的分发环节。Forge 产出带版本的模型与应用；Horizon 把它们——连同
Edge 自身——发布为 Open Horizon 服务定义、模式与策略，中枢代理再铺到现场节点。
随后 Edge 在这些节点上运行，并把数据回传 Link。

- **Forge → Horizon：**带版本的制品变成可分发的服务。
- **Horizon → Edge：**边缘运行时及其工作负载的策略化发布。见
  [边缘分发指南](../deployment/edge-delivery.md)。
- **Sphere / Identity：**全套件部署时，运维经 Sphere 一次登录即可从统一门户进入
  Horizon。见 [SSO 与 OIDC](../security/sso-oidc.md)。
- **独立运行：**Horizon 也可以单独作为中枢控制台运行。

## 技术一览

本节面向技术评估人员；以上内容均无需边缘运维经验即可阅读。

| 方面 | 说明 |
|---|---|
| 是什么 | Open Horizon 管理中枢的 Web 运维控制台 |
| 定位 | 闭环中的分发与部署环节 |
| 管理资源 | 节点、服务、模式、部署与管理策略、协议机器人、高可用组、组织、中枢用户 |
| 签名 | 服务部署配置在创建与更新时自动签名 |
| 访问模型 | 经 Sphere/Identity 或直连 OIDC 单点登录；跨组织管理员与组织内合作伙伴角色；合作伙伴只读 API 密钥 |
| 审计 | 只追加日志记录每个控制台与 API 密钥动作，含实际访问的中枢端点 |
| 高可用 | 高可用节点组，支持成员关系与网络配置管理 |
| 安全 | 服务端会话、凭据静态加密、加固 TLS 与安全响应头 |
| 离线能力 | 预制镜像气隙安装；断连现场由代理自主对账 |
| 部署 | 可独立运行，也可作为套件一部分 |
| 技术栈 | React + Vite 前端，Express / Node.js BFF 后端，PostgreSQL |
| 许可证 | Apache-2.0 |
