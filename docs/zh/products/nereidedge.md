# NereidEdge

NereidEdge 是现场网关上的**翻译官兼值守员**。它部署在机器和相机旁边，听得懂它们的
各种协议，再把数据用平台统一的语言回传给 [NereidLink](nereidlink.md)。广域网断了，
它就在本地继续干活、把一切记下来，网络恢复后自动补齐——数据不丢，也不会重复上报。

对于需要管理大量分散现场的团队，Edge 回答的是这些问题：

- "PLC、相机、传感器各说各话，谁来做翻译？"
- "工厂外网一断就是几个小时，数据和控制会瘫痪吗？"
- "要铺开几百个网关，能不能不派工程师去现场？"
- "怎么保证每个网关跑的都是同一套经批准的配置？"
- "远程现场此刻到底什么情况？"

## Edge 能帮你做什么

### 听得懂每一种设备语言

Edge 运行在现场网关上，与 EdgeX Foundry 边缘栈并肩工作，收集南向设备服务的事件与
读数，再转换为 Link 能理解的网关遥测格式。现场设备名被映射为平台子设备，无需为每台
设备单独做云端集成。

### 网络中断也照常运转

广域网时断时续甚至长期缺失，在这里被当作常态而非事故。Edge 用存储转发队列在本地
缓存数据，连通后从精确的断点续传——没有缺口，也没有重复。平台不可达期间，本地控制
与设备连接照常运行。

### 网关规模化、安全入网

每个网关都通过声明式配置驱动的认证加密链路接入平台。连接时必须先完成握手协商能力，
即便使用证书认证也强制要求凭据标识，心跳按协商节奏执行。新现场上线因此变成复制一套
成熟配方，而不是手工拼装服务器。

### 配置漂移自动愈合

连接器定义——设备如何接入平台——由中心下发，Edge 负责应用、更新与删除。若有人在带外
删除了设备，下一轮对账会自动修复；平台托管的属性缓存在本地，每次重连时刷新，删除
操作也会同步生效。新增连接器类型无需改动通信协议。

### 如实汇报现场状况

设备首次上数时自动登记、关停时自动撤销在线状态；Edge 每五分钟发送一次完整设备
清单，状态变化时随时上报运行时影子。Link 侧的运维人员始终知道哪些网关在线、各自
挂着什么设备。

### 有 AI 运行时时，顺带桥接推理能力

Edge 自身从不接触视频帧、也不调用模型。当同一网关上安装了 NereidInference 时，Edge
可以额外把模型目录、绑定与状态桥接到平台；如果没有安装推理服务，它的行为与不具备
该特性时完全一致，字节级相同。

## 一个网关心的上线过程

1. **启动**——由 [NereidHorizon](nereidhorizon.md) 分发并管理版本的 Edge 服务在
   现场网关上启动。
2. **握手**——向 Link 认证身份，协商特性与心跳节奏。
3. **挂接**——现场设备在首次遥测到达时自动注册。
4. **运行**——读数向北流动，指令与连接器定义向南下发；本地影子记录真实状态。
5. **抗压**——广域网中断由本地缓存吸收。
6. **恢复**——重连后从断点补传数据，并重新同步完整清单。
7. **更新**——Horizon 滚动发布新版本与新策略，无需奔赴现场。

## 在套件中的位置

Edge 是闭环中位于现场设备与 Link 之间的南向边缘一跳，由 Horizon 负责部署。

- **设备 → Edge：**边缘网关收集南向设备服务的事件与读数流。
- **Edge → Link：**遥测、在线状态、属性与影子上行；指令与连接器定义下行。
- **Horizon → Edge：**分发环节。Horizon 发布在网关上运行 Edge 的服务定义与策略；
  Edge 自身不带升级机制。
- **Forge：**Edge 在现场运行的模型与应用由模型工厂生产、经 Horizon 分发。

## 技术一览

本节面向技术评估人员；以上内容均无需边缘计算背景即可阅读。

| 方面 | 说明 |
|---|---|
| 是什么 | 把现场设备接入 Link 的边缘代理 |
| 定位 | 闭环的南向边缘一跳 |
| 运行位置 | 现场网关，与 EdgeX Foundry 4.0.2 边缘栈并肩运行 |
| 服务身份 | EdgeX 应用服务，服务键 `nereid-edge`，HTTP 端口 59750 |
| 北向 | 经 MQTT 网关协议（`v1/gateway/*`）把设备桥接进 Link，支持明文或 TLS |
| 韧性 | 存储转发缓存加断点续传；断网期间本地自治 |
| 生命周期 | 握手与特性协商、心跳、五分钟完整清单、设备影子与漂移对账 |
| 连接器 | 声明式、平台下发、自动愈合；扩展新类型无需改通信协议 |
| 推理 | 可选 ADR-0039 桥接，由静态开关加对推理管理设备 30 秒存在性探测双门控 |
| 分发 | 由 Horizon 交付与更新；无自带固件升级机制 |
| 状态 | 持久状态位于 `/app/data`，静态加密的密钥副本，稳定的 32 字节密钥文件 |
| 技术栈 | 基于 EdgeX App Functions SDK 的 Go 应用服务 |
| 许可证 | Apache-2.0 |
